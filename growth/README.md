# 🚀 Growth Tracker — 实习 & 就业冲刺（2026-06 → 2027-07）

> 目标：悉尼大学 Digital Health & Data Science 硕士在读，主攻 **健康数据科学 / 数据分析（BI）** 双线，
> 在毕业前拿到澳洲实习经历，提升 Graduate Program 与毕业就业竞争力。

这个目录是我的**问责账本（accountability ledger）**。它的存在是为了对抗一件事：偷懒。

## 它怎么运作

1. **每天早上**，GitHub Action 会自动开一个「📋 每日进展」Issue 进我的邮箱 —— 这是逃不掉的闹钟。
2. **我每天来汇报**：昨天交付了什么、今天卡在哪、今天承诺交付什么。
3. **Claude 当教练**：检查我昨天承诺有没有兑现（没兑现就追问为什么），派当天的具体任务，每周对照 roadmap 复盘。
4. **连续记录 = 进度条**：commit 绿格子 + 打卡连续天数 = 给面试官看的「13 个月持续投入」证据。

## 三条铁律

1. **产出导向**：不写「学了 SQL」，写「用 SQL 在 job_alerts 数据上写了 3 个分析查询并 commit」。有链接、有证据。
2. **每天最小可交付**：再忙也要有一个 commit / 一行进展。断签了就在日志里诚实写明原因。
3. **每周必复盘**：周日对照 roadmap，偏了就拉回来。
