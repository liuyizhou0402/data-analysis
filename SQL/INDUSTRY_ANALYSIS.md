## 0. 一句话投资逻辑（Executive Summary）

> TikTok 是过去十年全球数字广告增速最快的新增供给方。它的商业化引擎 GBS 本质上是在把「全球最强的注意力资产」变现为广告收入；而**代理商（Agency）渠道是 GBS 在中腰部市场（SMB/中型广告主）实现规模化、低边际成本扩张的杠杆**。投资人真正该盯的不是单个广告主，而是**代理商这层「分销网络」的健康度与复利增长**——谁能放大平台预算、谁能跨行业/跨产品迁移、谁的客户留存高，谁就是平台 ROI 最高的增长资产。

三条核心判断：

1. **从「品牌广告」转向「效果+电商闭环」**：TikTok 的第二增长曲线是 TikTok Shop / 内容电商，这把广告从「花钱买曝光」变成「花钱直接卖货」，大幅抬高广告主的付费意愿与预算天花板（ROI 可归因）。
2. **成熟市场是存量份额争夺，新兴市场+电商是增量**：澳新（ANZ）这种成熟数字广告市场，TikTok 主要从 Meta/Google 手里抢「时间份额→预算份额」；真正的净增量来自电商化和中小广告主自助化。
3. **代理商是「带杠杆的增长」**：一个高潜力代理商能同时带来 N 个广告主、跨多个行业、并主动采用新广告产品，平台对其的边际服务成本远低于直客——这正是这个岗位（Agency Partner）存在的商业意义。

## 2. 产业链上下游拆解

### 上游（供给侧 / 成本侧）
- **内容供给**：创作者、MCN、UGC——决定广告库存的「量」与「质」。库存越优质，CPM 越高。
- **算法与基础设施**：ByteDance 的推荐系统是核心护城河，决定广告定向效率（即广告主的 ROI）。
- **创意供给**：Spark Ads（用原生内容投流）、创意工具、TikTok Creative Exchange——降低广告主制作门槛，是提升 eCPM 的关键。
- **成本结构**：服务器/带宽、内容审核、创作者激励、销售与代理返点（**返点=渠道获客成本**）。

### 下游（需求侧 / 营收侧）
- **直客（大客户/KA）**：大品牌，预算大、要求品牌安全与定制化，通常直营团队服务。
- **代理商渠道（本岗位重点）**：覆盖中小与中腰部广告主，**以规模和广度取胜**。
- **自助投放（SMB self-serve）**：长尾商家自己开户投放，边际成本最低，是利润率最高的部分。
- **电商商家（TikTok Shop）**：把广告与成交闭环，是预算弹性最大的新需求。

### 关键洞察（投资视角）
> 广告平台的「毛利杠杆」来自**把库存卖给边际服务成本最低的需求方**。直客服务重、利润率低；代理商一对多、杠杆高；自助投放最轻、利润率最高。**代理商渠道是平台从「重人力直营」走向「规模化分销」的中间形态**——经营好它，等于用有限的销售人力撬动数倍预算。

## 3. 营收与利润：商业模式拆解

### 收入构成
1. **广告收入（绝对主体）**：In-Feed Ads / TopView / Brand Takeover / Branded Effect / Spark Ads，按 CPM/CPC/oCPM 计费。
2. **电商佣金（TikTok Shop）**：GMV 抽佣 + 商家广告（货架/内容电商），增速最快。
3. **其它**：直播打赏分成、订阅等（占比小）。

### 单位经济学（广告主视角的飞轮）
```
更多优质内容 → 更长用户时长 → 更多广告库存
   ↑                                    ↓
更高 ROI ← 更好的算法定向 ← 更多广告主数据/预算
```
> 这个飞轮一旦转起来，**eCPM（每千次展示收入）上升 = 平台营收的核心驱动**。营收增长 = 库存量 × 填充率 × eCPM。代理商的作用是抬高「填充率 × eCPM」——把更多预算、更优创意带进来。

### 利润增长的来源（投资人该问的）
- **量**：MAU 与时长（成熟市场已近饱和，靠时长与新场景）。
- **变现率（monetization rate）**：单位时长的广告加载与定价，仍有提升空间，尤其电商化。
- **结构优化**：渠道从直营→代理→自助迁移，**降低获客边际成本**。
- **电商闭环**：把外部 ROI 内化为可归因 GMV，**直接抬高广告主付费意愿**。

### 量级感（行业估算，非官方）
- ByteDance 总营收已达千亿美元级别，TikTok 全球广告收入处于**数百亿美元量级且仍双位数增长**。
- TikTok Shop 在东南亚、英美快速放量，是增速最高的板块。
- 澳新（ANZ）数字广告盘子约百亿澳元级，TikTok 是其中份额仍在爬升的「挑战者」。

## 4. 市场在哪里？（地理与本岗位的 ANZ 视角）

| 市场 | 特征 | 对代理商业务的含义 |
|------|------|---------------------|
| **东南亚（SEA）** | 增量主战场，TikTok Shop 渗透高 | 电商代理、跨境代理是金矿 |
| **美国** | 最大单一广告市场，监管/地缘风险最高 | 高 ARPU，但政策不确定 |
| **欧洲** | 成熟、合规（GDPR/DSA）门槛高 | 品牌安全、合规型代理价值高 |
| **澳新 ANZ（本岗位）** | 成熟、高 ARPU、英语市场、品牌主导 | **存量份额争夺**为主，靠抢 Meta/Google 预算 + 电商新场景做增量 |

> **ANZ 市场判断**：澳洲是高人均广告价值的成熟市场，TikTok 在这里不是「从 0 到 1」，而是「从挑战者到主力媒介」的份额迁移战。代理商在 ANZ 的价值在于：**帮本地品牌把预算从传统社媒/搜索切换过来**，并教育市场用好电商与效果广告。这也解释了 JD 第 2 条「research competitors' advertising activities」——盯的就是 Meta/Google 的预算流向。

## 6. 竞争格局：存量还是增量？

### 结论：**双轨制——成熟市场存量博弈，电商与长尾是增量。**

| 维度 | 存量博弈 | 增量空间 |
|------|----------|----------|
| 地区 | 美/澳/欧成熟市场 | 东南亚、新兴市场 |
| 预算类型 | 抢 Meta(Reels)/Google(Shorts/YouTube) 的品牌+效果预算 | 电商 GMV、SMB 自助新开户 |
| 场景 | 短视频信息流广告 | 内容电商、零售媒体、搜索广告化 |

### 主要竞争对手
- **Meta（Instagram Reels / Facebook）**：最直接对手，效果广告基建成熟、归因强。
- **Google（YouTube Shorts / 搜索）**：抢视频与意图流量。
- **Amazon / 零售媒体网络**：抢电商广告预算（高意图、强归因）。
- **Snap、其他本地平台**：边缘竞争。

> **存量战的本质是「时间份额 → 预算份额」的转化效率**：TikTok 已经赢得了用户时长，但广告预算的迁移滞后于注意力迁移——这个「剪刀差」就是 GBS（和代理商）要去关闭的增长空间。**代理商是关闭剪刀差的销售毛细血管。**

## 7. 未来增长点（投资人最关心）

1. **TikTok Shop / 内容电商闭环**：把广告 ROI 从「不可归因的品牌曝光」变成「可归因的 GMV」，结构性抬高广告预算天花板。**最大增长极。**
2. **效果广告 + AI 自动化投放**：智能出价/自动化创意（类 Smart+/ASC），降低中小广告主门槛，提升 eCPM 与填充率。
3. **SMB 自助化**：长尾商家自助开户，边际利润最高，规模化潜力大。
4. **零售媒体 & 搜索广告化**：站内搜索、商品广告，复制 Amazon/字节国内（巨量/电商广告）的成熟路径。
5. **测量与归因升级**：在隐私新政（ATT、Cookie 退场）下，第一方数据与平台内归因成为竞争壁垒。
6. **新兴市场 + 跨境**：东南亚、拉美、中东的渗透与跨境电商代理。

> **对代理商业务的映射**：未来高价值的代理商，是那些**率先采用新产品（TikTok Shop、Spark Ads、自动化投放）、并能跨行业复制成功打法**的代理商。这正是「高潜力」的产品级定义。

## 8. 代理商（Agency Partner）模式深度拆解 —— 岗位的核心

### 平台为什么要做代理商渠道？
- **杠杆**：一个代理商 = 一批广告主，用有限销售人力撬动数倍预算。
- **覆盖**：触达直营够不到的中小/区域/垂直行业客户。
- **教育**：代理商承担创意、投放、优化的服务，降低平台服务成本。

### 激励机制（JD 第 3 条「commission incentive policies」）
- **分级（Tier）体系**：按消耗规模/增长把代理商分 Tier 1 / Tier 2…，对应不同返点率与资源。
- **返点/Rebate**：达到消耗阈值给佣金返点（你 SQL 项目第三题就是在监控这个）。
- **季度/大促激励**：大促期间额外激励，撬动预算前置投放。

> **投资视角的风险**：返点是**渠道获客成本**。激励设计得好 → 用补贴撬动超额增量预算（正 ROI）；设计得差 → 补贴了本来就会发生的消耗（负 ROI，「补贴空转」）。**Agency Partner 团队的数据工作，本质是优化这笔渠道补贴的 ROI。**

## 9. 如何识别高潜力 TikTok 代理商？（可落地的评分框架）

> 这是岗位的灵魂问题，也是把你那套 SQL 分析「升维」成商业判断的地方。下面给一个 **6 维度评分模型**，每个维度都能用你 `tfn_ad_spend_daily` / `tfn_tiktok_agents` 的数据算出来。

| # | 维度 | 含义（为什么重要） | 可量化指标（对应 SQL） |
|---|------|---------------------|------------------------|
| 1 | **增长动能 Momentum** | 环比/同比消耗增速，识别黑马 | MoM/YoY 增长率（`LAG()` 窗口函数，如 Agent 104 +200%） |
| 2 | **行业广度 Diversification** | 跨行业=抗风险+可复制 | `COUNT(DISTINCT industry)` 随时间增加（如 101 从电商拓到 Gaming） |
| 3 | **产品采纳 Product Adoption** | 是否用新产品（Spark Ads/Shop） | `COUNT(DISTINCT product_type)`、新产品首投日期 |
| 4 | **客户质量 & 留存 Retention** | 客户是否持续投、不流失 | 活跃客户数、连续投放月数、消耗集中度（HHI） |
| 5 | **钱包份额空间 Headroom** | 占客户总预算比例，越低=空间越大 | 该代理消耗 vs 行业基准、Tier 内排名分位 |
| 6 | **政策达标 & 弹性 Policy Fit** | 是否临近返点阈值（撬动点） | 距 Rebate 阈值的缺口（`CASE WHEN` + 缺口金额） |

### 综合打分（示例公式）
```
高潜力得分 = 0.30·增长动能 + 0.20·行业广度 + 0.20·产品采纳
           + 0.15·客户留存 + 0.10·钱包空间 + 0.05·政策弹性
```
（权重按业务目标调；重增长就加大 Momentum，重稳健就加大 Retention。）

### 三类「高潜力画像」
1. **黑马型（Rising Star）**：基数不大但增速极高（如 Agent 104），需快速给资源升 Tier。
2. **横向扩张型（Diversifier）**：在多行业/多产品复制成功打法（如 Agent 101 从电商进游戏），可复制性强。
3. **沉睡巨人型（Sleeping Giant）**：消耗大但增速放缓、钱包份额低——有规模、有空间，靠激励/新产品激活。

### 反向信号（识别「衰退/低潜力」）
- 连续多月消耗下滑（如 Agent 102）。
- 单一行业/单一客户依赖（集中度过高，脆弱）。
- 只用最基础产品、不采纳新品（增长见顶）。
- 拿了返点但增量来自存量预算搬运（补贴空转）。

> **面试落地话术**：「我会把代理商当成一个『投资组合』来管理——用增长动能找黑马、用行业广度和产品采纳判断可复制性、用钱包份额估算上行空间、再用返点阈值缺口决定把激励预算投给谁的边际 ROI 最高。我那个 SQL 项目里的 `LAG` 环比和 `CASE WHEN` 政策监控，就是这套框架最底层的两块积木。」

## 11. 风险与不确定性（投资人必谈）

- **地缘/监管风险**：美国剥离/封禁压力、各国数据合规（隐私新政削弱归因）。
- **竞争加剧**：Meta/Google 在短视频与效果广告的反扑。
- **宏观广告周期**：广告是顺周期开支，经济下行先砍预算。
- **电商执行风险**：TikTok Shop 履约、信任、退货等运营难题。
- **渠道补贴 ROI**：激励政策若设计不当会侵蚀利润（即第 8 节的「补贴空转」）。
