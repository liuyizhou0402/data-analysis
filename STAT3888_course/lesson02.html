Lecture 02

Data Cleaning &amp; Preprocessing

Garbage in, garbage out. How to turn a messy survey into an analysis-ready matrix.

STAT3888 · Statistical Machine Learning The University of Sydney · School of Mathematics & Statistics

Learning objectivesBy the end of this lecture you can…

  • Diagnose common data-quality problems: missingness, outliers, inconsistent types.
  • Distinguish MCAR / MAR / MNAR missingness and choose a sensible response.
  • Apply standardisation and other transforms, and know when they matter.
  • Build a reproducible cleaning pipeline in R.

Why cleaning dominates real projects

Surveys and lab data are never tidy: typos, impossible values, mixed units, duplicate rows, free-text where numbers belong, and gaps everywhere.

The tidy-data target

Each row = one observation, each column = one variable, each cell = one value. Your goal is a clean numeric/factor matrix.

Reproducibility

Never edit the raw file by hand. Every fix lives in a script so it can be re-run, reviewed, and trusted (GQ4).

DiagnoseStep 1 — see the missingness

A missing-data map reveals patterns: variable V5 has a block of missing values (possible skip-logic), while others are scattered.

Three mechanisms

MCAR — missing completely at random (rare, benign).

MAR — missingness depends on observed variables (handle by conditioning).

MNAR — depends on the unobserved value itself (dangerous, e.g. under-reporting high intake).

What to do about missing values

StrategyWhenRisk
Complete-case (drop rows)Few, MCARBias + lost power if not MCAR
Mean/median imputationQuick baselineShrinks variance, distorts correlations
Model-based / kNN imputationMARNeeds care, can leak
Multiple imputation (mice)Principled inferenceMore complex
Rule of thumb: impute using the training data only, then apply the same rule to test data — otherwise you leak information and over-state performance.

Outliers, types & sanity checks

Range & logic checks

Energy intake of 80,000 kJ/day? Age of 200? Negative weight? Define plausible ranges and flag violations.

Robust detection

Prefer median & IQR over mean & SD when hunting outliers — the mean is itself dragged by the outlier.

An outlier is not automatically an error. Investigate before you delete — it may be the most interesting participant in the study.

TransformStep 2 — put variables on comparable scales

Energy (kJ) and Vitamin C (mg) live on different scales. Distance-based methods (k-means, PCA, k-NN) are dominated by the large-scale variable unless you standardise.

zi = ( xi − x̄ ) / s

Also common

log-transform skewed intakes; min–max scale to [0,1]; encode categoricals as factors / dummies.

A reproducible cleaning pipeline in R

library(tidyverse)

clean <- raw %>%
  janitor::clean_names() %>%              # tidy column names
  distinct() %>%                          # drop duplicate rows
  mutate(sex = factor(sex),
         energy_kj = na_if(energy_kj, 0)) %>%   # 0 = not recorded
  filter(between(age, 18, 100)) %>%       # logic check
  mutate(across(where(is.numeric),        # standardise numerics
                ~ as.numeric(scale(.))))

skimr::skim(clean)   # profile the result
Chain each fix with %>% so the whole pipeline is one auditable object.

SummaryKey takeaways

  • Cleaning is most of the work — do it in a script, never by hand.
  • Diagnose missingness first; the mechanism (MCAR/MAR/MNAR) dictates the fix.
  • Fit imputation and scaling on training data only to avoid leakage.
  • Standardise before any distance-based method (next: clustering!).
