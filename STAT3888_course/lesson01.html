Big pictureWhat is statistical machine learning?

The goal

Build algorithms that learn patterns from data to make predictions or discover structure — without being explicitly programmed for the task.

Statistics meets ML

Classical statistics asks “is this effect real?” (inference). ML asks “how well can I predict the next case?”. This unit lives at their intersection.

Two cultures (Breiman, 2001): the data-modelling culture assumes a stochastic model; the algorithmic culture treats the mechanism as unknown and optimises prediction. Good data scientists move fluidly between both.

Supervised vs unsupervisedThe two families you will learn

Left: unsupervised — we only see the points and must find the groups. Right: supervised — each point carries a known label and we learn the rule.

How to tell them apart

Is there a target variable Y?

✔ Yes → supervised (regression if Y is numeric, classification if categorical).

✘ No → unsupervised (clustering, dimension reduction).

In-class exerciseWarm-up: classify the task

For each scenario, decide supervised or unsupervised, and name the sub-type (regression / classification / clustering / dimension reduction):

  1. Predict a person's fasting glucose from 30 dietary intake variables.
  2. Group 500 participants into dietary patterns with no pre-defined labels.
  3. Flag whether a food diary entry is plausible or a data-entry error.
  4. Compress 200 correlated nutrient measurements into a handful of indices.
Hint. Ask first: is there a target variable Y, and if so, is it numeric or categorical?

SummaryKey takeaways

  • ML learns patterns from data; it sits between classical inference and pure prediction.
  • Supervised = labelled Y (regression/classification); unsupervised = structure discovery.
  • The workflow — clean → model → evaluate → communicate — is iterative, not linear.
  • Your project is interdisciplinary: the statistics is necessary but not sufficient.
