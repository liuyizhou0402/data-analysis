## 设计规范

集中定义在 `build_deck.js` 顶部的 `C`（配色）与 `F`（字体）两个常量里。

- 底色 `0C1622`，面板 `14202E`，描边 `26384C`
- 强调色金 `C9A227`；方向色仅用于涨跌：绿 `47A883` / 红 `E0605A`
- 标题与数字用 Cambria，正文用 Arial（两者都是 Office 自带字体，跨机器不会替换）
- 页边距 0.62"，正文区 1.86"–6.70"，页脚 6.90"

改版式时改常量，不要在生成后的 XML 上手工修补。
