# 06 · 私域承接脚本库：从"领资料"到"成单"全链路话术

> `03` 讲的是转化漏斗的**策略框架**；这一篇给你**逐字可抄的话术脚本**——公众号自动回复、加微信破冰、诊断邀约、试听转化、异议应答、跟进转介绍。复制改名即用。

## 一、公众号搭建（私域枢纽）

公众号是大陆唯一能**合规承接 + 自动化**的私域入口。小红书的人 → 公众号领资料 → 加微信，闭环就通了。

## 二、加微信破冰（第一句定调子）

**核心：先送达价值，不要上来就推销。** 通过好友后第一条消息——

### 场景 A：为领资料而来
```
你好呀～我是阿轩老师👋 看到你来领资料，先发你～
【发送 PDF：公式速查卡 / FRQ模板】

孩子现在 AP生物大概什么情况呀？几年级、目标几分、
哪块比较吃力？方便的话简单说说，我帮你看看～
```
> 一句话送资料 + 一句话开启对话（顺势收集信息，为诊断铺垫）。

### 场景 B：为咨询课程而来
```
你好～我是阿轩老师👋 别急着聊课程，咱先看看孩子的真实情况，
我才好判断怎么帮得上。

方便的话，把他最近一份生物卷子/FRQ拍给我，
我免费做一份薄弱点诊断，看准问题再决定要不要一起学，
你看行不？
```
> 把"卖课"转成"先诊断"——降低戒心，又展示专业。

## 三、朋友圈前 30 条（无声的销售员）

家长加了你，**第一件事是翻你朋友圈**。前 30 条决定第一印象，按这个配比铺：

| 类型 | 占比 | 内容示例 |
|------|:---:|----------|
| 专业输出 | 40% | "今天给学生讲FRQ评分点，Explain和Describe差一个词就差2分"（配教师版截图）|
| 学员进步 | 25% | "学生月考生物92，FRQ满分🎉 入学时还卡在3分"（打码，经同意）|
| 教学理念 | 20% | "我为什么坚持先给孩子做诊断——看不准病根，提分就是碰运气"|
| 真人温度 | 15% | 读到的一篇生物科普、对教育的看法、备课日常 |

> 💡 起步没学员案例？先发**专业输出+理念**立住人设，种子学员一出效果立刻补案例。

**发圈节奏**：每天 1–2 条，别刷屏；专业和生活穿插，让人觉得"真实、靠谱、有温度"。

## 四、成交全链路 SOP（5 个节点话术）

```
领资料 → ①破冰收集信息 → ②邀约诊断 → ③交付诊断报告
       → ④邀约试听 → ⑤成交报名
```

### 节点 ② 邀约诊断
```
听你这么说，孩子的情况我大概有数了。这样吧——
你把他最近一次生物考试/一份FRQ答卷拍给我，
我按 College Board 的评分标准，帮他做一份《薄弱点诊断报告》：
看准他是「概念不牢」还是「答题不会拿分」，再给提分路径。
完全免费，就当帮孩子做个体检🩺 你看方便发我吗？
```

### 节点 ③ 交付诊断报告（关键专业展示）
> 用 `03` 的诊断报告模板，做成半页清晰图文发过去，然后：
```
报告做好了，你看一下👆
简单说，孩子主要丢分在两块：
①U3、U6两个单元概念没打通（这是高权重单元，必须先补）
②FRQ审题动词混淆，Explain答成Describe，机制分一直丢

好消息是——这两块都是「方法能解决」的问题，不是智商问题。
按 3C 穿透法走，先重建概念、再练答题模板，6–8周能看到明显变化。

我可以先带孩子上一节课试试，用他最弱的U3走一遍，
让他自己感受下"原来能听懂"。要不先约个试听？
```

### 节点 ④ 邀约试听
```
试听就用一节真实正课（比如U3光合 或 FRQ模板课），
不是走过场——上完孩子能当场弄懂一个之前卡住的点，
你也能看看我的教法适不适合他。
时间你定，[周末/晚上] 哪个方便？
```

### 节点 ⑤ 成交报名
```
孩子试听反馈不错，那我们就正式开始～
我建议先从 U3 开始，每周 X 次，先排个 [10/20] 课时，
配套教材、错题跟踪、FRQ精批我都会跟上。
课时包是 [按你的定价]，咱先把第一阶段的计划和时间定下来😊
```

## 五、异议应答库（背下来，临场不慌）

| 家长说 | 你这样回 |
|--------|----------|
| **"效果怎么样？"** | "我不敢拍胸脯保分，那是不负责任。但我能保证方法和体系——先让孩子做个诊断、上节试听，看准问题、感受教法，再决定值不值，这样你最踏实。" |
| **"多少钱？"** | "价格我一定透明告诉你，但得先看孩子情况才好定方案。要不先免费做个诊断？看准了需要几课时、怎么补，报价才有意义。" |
| **"能保证上5分吗？"** | "❌ 保不了——任何说保分的都别信。我能保证的是：用对方法、把该补的补上、把答题练到位，努力到位了结果不会差。这是我能负责的部分。" |
| **"别家更便宜"** | "便宜的是课时单价，值钱的是提分的确定性。我贵在有完整体系、教材、模考和逐题精批，而且我对每个孩子负责到底。你可以先试听对比，合适再说。" |
| **"再考虑一下"** | "完全理解，不催你😊 资料先给孩子用着，他做题有不会的随时拍给我，我帮看。等你想清楚了我都在。" |
| **"孩子基础太差"** | "基础弱反而是我擅长的——3C 第一步就是重建概念。诊断报告里我会标出最该先补的单元，一步步来，别急。先做个诊断看看？" |
| **"时间能配合吗"** | "可以，时间咱们一起排，周末或晚上都行。先把孩子最弱的单元安排上，灵活调整。" |

> 🔑 异议应答的统一内核：**不逼单、不吹牛、把球导向"先诊断/先试听"**——用专业体验代替嘴上承诺。

## 六、跟进话术（没成交的别浪费）

意向但没立刻成交的，**别删别催，持续养**：

**轻触发（隔 3–5 天，给价值不推销）**：
```
对了，这两天整理了一份《U3能量代谢易错点》，
孩子上次卷子在这块丢了分，发你给他看看👇【发干货】
```

**考试季触发**：
```
快到AP考试了，孩子复习得怎么样？
要是想冲刺阶段抓重点，我可以帮他过一遍高频考点，
有需要随时找我～
```

> 持续在朋友圈输出专业+案例，意向家长会被"养熟"，时机到了自然回来找你。

## 七、转介绍话术（老带新最高效）

**时机**：学员**刚出成绩、最满意**时开口，成功率最高。

```
太替孩子高兴了！这次进步是他自己努力的结果👏
对了，如果你身边有同样为生物发愁的家长，
也欢迎介绍给我——我一样会先免费帮孩子诊断、看准了再说。
（介绍成功的话，给孩子加 [X课时/资料] 作为感谢🙏）
```

> 国际学校家长圈子小、群密集，**一个满意家长能带一串**。口碑是这个市场最强的增长引擎。

## 八、私域承接红线（别踩）

- ❌ 不承诺保分 / 保 offer（违规 + 失信）
- ❌ 不伪造案例 / 截图（穿帮即 IP 崩塌）
- ❌ 不在小红书硬留微信（封号）
- ❌ 不逼单、不贬低同行
- ✅ 真实案例需经家长/学员同意、隐私打码
- ✅ 先给价值、再谈成交——信任是慢功夫，但最牢
