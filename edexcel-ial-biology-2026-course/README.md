# Edexcel IAL Biology 2026 · 24 节专题课（PPT + 动画创意）

> 面向国际学校学生的 **Pearson Edexcel International A Level Biology** 全程专题课。
> 中英双语 · 对标 IAL 6 个 Unit · 每节课 **≥100 页 PPT** + **配套教学动画创意脚本**。
> 教材依据：**Pearson Edexcel International A Level Biology Student Book 1 & 2**（8 Topics，每 Topic 含 A/B/C 三个 sub-unit）。

---

## 这是什么 / What this is

把整本教材的 **8 个 Topic × 3 个 sub-unit = 24 个 sub-unit**，每个 sub-unit 做成**一节可直接开讲的大课**：

- **主讲 PPT（≥100 页）**：覆盖该 sub-unit 全部教材小节，含核心概念精讲、🖼️ 图示描述、必背术语、A\* 深化、易错点、**当堂练习 + 评分点答案**、实验技能、数学技能、考试冲刺、知识结构图。
- **教学动画创意脚本**：每节课 3–5 个动画/短视频创意（分镜 + 中英旁白 + 视觉风格 + 工具建议），专攻最难讲清的概念。

格式为 **Marp Markdown**，VS Code 装 Marp 插件即可一键导出 **PPTX / PDF**，纯文本、可版本管理、可持续迭代——是你自己的**个人 IP 教材**。
