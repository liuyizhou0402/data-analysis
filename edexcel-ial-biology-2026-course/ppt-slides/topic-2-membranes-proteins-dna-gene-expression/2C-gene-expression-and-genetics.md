## 先修知识快速回顾 / Prior Knowledge（接 2B）

开始前你需要记得（来自 2A/2B）：

- **Gene 基因** = 编码一条多肽(或功能 RNA)的 DNA 片段；**locus 位点** = 基因在染色体上的位置。
- **Triplet code 三联体密码**：每 **3 个碱基**编码一个氨基酸；**codon 密码子**在 mRNA 上。
- **Degenerate code 简并性**：多数氨基酸由 **不止一个**密码子编码（共 64 个密码子编 20 个氨基酸 + stop）。
- **Transcription → Translation**：DNA → mRNA → polypeptide；碱基顺序决定氨基酸顺序决定蛋白质形状决定功能。
- **Diploid 二倍体**：体细胞每个基因有**两份**（来自父母各一条同源染色体）。

> 🧠 一句话：**碱基顺序 → 氨基酸顺序 → 蛋白质形状 → 功能**。本课先看这条链如何"断"(突变)，再看它如何"传"(遗传)。

# Section 1 🧬
# Gene Mutation
# 基因突变

本节预告：mutation 是碱基序列的改变；substitution（silent / missense / nonsense）、insertion、deletion 与 **frameshift**；单碱基改变为何**可能/可能不**改变蛋白质（链接简并性）；mutagens；镰刀型细胞作为替换的经典例子。

---

## 🪝 Hook：一个字母改变一生

- **Sickle cell anaemia 镰刀型细胞贫血症**：β-globin 基因中**仅一个碱基**由 A 变 T（DNA 模板上 CTT→CAT）。
- 结果：mRNA 一个密码子由 GAG→GUG，第 6 位氨基酸由 **glutamic acid (Glu)** 变成 **valine (Val)**。
- 一个氨基酸的改变 → 血红蛋白在低氧时**聚合成纤维** → 红细胞**镰刀化** → 堵塞毛细血管、贫血。
- 🤔 思考：一个碱基的改变就能致病；但**有些**碱基改变却**毫无影响**——为什么？答案在简并性里。

> 🖼️ 图示：正常圆盘状红细胞 vs 镰刀状红细胞并列；下方放大 DNA 序列，仅一个碱基高亮(A→T)，箭头指向氨基酸 Glu→Val。

---

## 什么是基因突变？/ What is a gene mutation?

- **Gene mutation 基因突变**：DNA 中**碱基序列(base sequence)的改变**。
- 发生时机：多在 **DNA replication（DNA 复制）** 时出错；可自发(spontaneous)或被诱发(induced)。
- 影响层级：碱基改变 → **可能**改变 mRNA 密码子 → **可能**改变氨基酸 → **可能**改变蛋白质形状/功能 → **可能**改变表型。
- 关键词是**"可能"**：每一步都不是必然——这正是本节核心。
- 若发生在 **gamete(配子)** 中 → 可**遗传**给后代；若在体细胞 → 一般不遗传(但可致癌)。

> 🖼️ 图示：流程箭头 DNA base change →(maybe)→ codon change →(maybe)→ amino acid change →(maybe)→ protein change →(maybe)→ phenotype change，每个箭头标 "?"。

---

## 突变类型①：Substitution 替换

- **Substitution 碱基替换**：一个碱基被**另一个**碱基取代（数目不变）。
- 只影响**它所在的那一个**密码子 → 影响**局限**（不会错位后面的密码子）。
- 三种可能后果（取决于新密码子编码什么）：
  - **Silent 沉默突变**：新密码子仍编码**同一个**氨基酸（靠简并性）→ 蛋白质不变。
  - **Missense 错义突变**：新密码子编码**不同**氨基酸 → 蛋白质改变（如镰刀型细胞）。
  - **Nonsense 无义突变**：新密码子变成 **stop codon** → 多肽**提前终止**，通常无功能。
- **所以呢**：substitution 是"最温和"的一类——因为它**最可能**因简并性变成 silent。

> 🖼️ 图示：一条 mRNA，第二个密码子中间碱基被替换；三条分支分别标 silent（同氨基酸）、missense（换氨基酸）、nonsense（变 STOP）。

---

## 为什么 substitution 可能"无害"？链接简并性

- 遗传密码 **degenerate（简并）**：64 个密码子编码 20 个氨基酸 + 3 个 stop → 多数氨基酸有**多个**密码子。
- 同义密码子常只在**第三位**碱基不同（"wobble 位"）。
  - 例：GAA 与 GAG 都编码 **glutamic acid**；UCU/UCC/UCA/UCG 都编码 **serine**。
- 所以第三位的替换**常常是 silent**：氨基酸序列不变 → 蛋白质形状/功能不变 → 表型不变。
- **因果链**：simplify → 简并性 → 同义密码子存在 → 某些碱基改变不改变氨基酸 → **silent mutation**。
- ⚠️ 反过来：若替换落在**第一/第二位**，更可能换氨基酸(missense)甚至变 stop(nonsense)。

> 🖼️ 图示：密码子表局部，highlight GAA 与 GAG 都指向 Glu；箭头标 "3rd base change → often silent"。

---

## 突变类型②：Insertion 插入 与 ③ Deletion 缺失

- **Insertion 插入**：序列中**加入**一个(或多个)额外碱基。
- **Deletion 缺失**：序列中**移除**一个(或多个)碱基。
- 若插入/缺失的碱基数**不是 3 的倍数** → 引发 **frameshift（移码）**：
  - 因为密码子是**每 3 个连续读取**，加/减一个碱基会让**插入点之后的所有密码子全部错位重读**。
- **所以呢**：frameshift 通常比 substitution **后果严重得多**——从突变点起几乎**整条**氨基酸序列都变，常提前遇到 stop。
- 例外：若插入/缺失**恰好 3 个**碱基 → 不移码，只增/减一个氨基酸（影响相对局限）。

> 🖼️ 图示：阅读框比喻——一排三格三格分好的方块（密码子），抽掉一个方块后，后面所有分隔线整体左移，颜色全乱。

---

## Frameshift 移码：为什么"一发不可收拾"

- 读取规则：核糖体从**起始密码子(AUG)** 开始，**不重叠地每 3 个碱基**读一个 codon。
- 没有"标点符号"分隔密码子 → **阅读框(reading frame)** 完全由**起点 + 连续计数**决定。
- 插入或缺失一个碱基 → 起点之后的**计数全部错位** → 后续每一个 codon 都读错 → 氨基酸序列从突变点起**完全改变**。
- 常见结果：很快出现一个**提前的 stop codon** → 多肽**截短** → 几乎肯定**无功能**。
- 对比记忆：**substitution = 改一个字母**；**frameshift = 把整句话往后挪一格重读**。

> 🖼️ 图示：句子类比 "THE CAT ATE THE RAT"，删去一个字母后变成 "THE ATA TET HER AT…"，整句话从删除点起全乱。

---

## 突变的影响：从"无"到"严重"的连续谱

| 突变类型 Type | 对碱基数 | 对阅读框 | 对蛋白质的典型影响 |
|---|---|---|---|
| **Silent** substitution | 不变 | 不变 | 无（氨基酸不变） |
| **Missense** substitution | 不变 | 不变 | 改一个氨基酸（可轻可重） |
| **Nonsense** substitution | 不变 | 不变 | 提前终止 → 截短/无功能 |
| **Insertion/Deletion**（非 3 倍数） | 改变 | **移码** | 突变点后全改 → 常无功能 |
| **Insertion/Deletion**（3 倍数） | 改变 | 不变 | 增/减一个氨基酸（较局限） |

> 🧠 排序口诀：影响通常 **silent < missense ≈ in-frame indel < nonsense ≈ frameshift**（视位置而定）。

---

## 突变的"严重性"还取决于什么？

- **位置 Position**：
  - 落在 **active site / 关键结合区** 的 missense → 影响大；落在不重要区域 → 影响小。
  - 落在内含子(intron)/非编码区 → 常无影响（IAL 层面理解即可）。
- **氨基酸性质改变程度**：换成性质相近的氨基酸(如疏水→疏水) → 影响小；性质迥异 → 影响大。
- **显隐性**：突变若产生**隐性等位基因**，杂合子(heterozygote)仍有一个正常拷贝 → 表型可能正常(carrier)。
- **细胞类型**：gamete 突变可遗传；体细胞突变只影响该个体（可能致癌）。

> 🖼️ 图示：一个酶的活性位点，左图突变落在活性位点(底物卡不进)，右图突变落在远处表面(几乎无影响)。

---

## Mutagens 诱变剂：加快突变的因素

- **Mutation rate 突变率**自然就存在(spontaneous)，但 **mutagens（诱变剂）** 会**提高**它(induced)。
- 三大类（必背例子）：
  - **Ionising radiation 电离辐射**：X-rays、gamma rays、UV（紫外，导致嘧啶二聚体）。
  - **Chemical mutagens 化学诱变剂**：tar in **tobacco smoke**（焦油，含多种致癌物）、mustard gas、某些染料。
  - **Some viruses 某些病毒**：可将自身 DNA 插入宿主基因组，扰乱基因。
- **所以呢**：mutagen → ↑突变率 → ↑有害突变机会 → ↑某些癌症风险（synoptic 接 1C 风险因素与 3C 致癌）。

> 🖼️ 图示：三个图标——辐射符号(UV/X-ray)、香烟(tar)、病毒颗粒——三箭头共同指向一段"碱基被改变"的 DNA。

## 案例：Sickle Cell 作为一次 missense substitution

- **类型**：single-base **substitution**（替换）→ **missense**（错义）。
- DNA 模板链：CTT → CAT；转录出 mRNA 密码子 **GAG → GUG**。
- 氨基酸：第 6 位 **glutamic acid (Glu) → valine (Val)**（亲水→疏水）。
- 后果链：疏水的 Val 暴露在外 → HbS 分子在**低氧**时**互相黏聚成纤维** → 红细胞**镰刀化(sickling)** → 易破裂(贫血)、堵塞微血管(疼痛危象)。
- A\* 亮点：杂合子(HbA HbS, **sickle cell trait**)在**疟疾**流行区有**生存优势**(疟原虫在镰变细胞中存活差) → 平衡选择(synoptic 接进化)。

> 🖼️ 图示：HbS 分子在低氧下聚合成长链纤维，把红细胞撑成镰刀形；旁注 "Glu→Val, hydrophobic patch"。

## Key Terms — Mutation 必背术语表

| English term | 中文 | 一句话定义 |
|---|---|---|
| Gene mutation | 基因突变 | DNA 碱基序列的改变 |
| Substitution | 替换 | 一个碱基被另一个取代（数目不变） |
| Silent mutation | 沉默突变 | 碱基改变但氨基酸不变（靠简并性） |
| Missense mutation | 错义突变 | 碱基改变导致氨基酸改变 |
| Nonsense mutation | 无义突变 | 碱基改变产生提前的 stop codon |
| Insertion / Deletion | 插入/缺失 | 加入/移除碱基 |
| Frameshift | 移码 | 非 3 倍数 indel 使后续密码子全部错位 |
| Mutagen | 诱变剂 | 提高突变率的因素 |
| Degenerate | 简并的 | 一个氨基酸由多个密码子编码 |

## A* Going Deeper：为什么 frameshift ≫ substitution

- 一个 substitution 只**重写一个密码子**；一个 frameshift **重写从突变点到链末端的所有密码子**。
- 概率上：随机的新阅读框很快(平均约每 20 个密码子)就会撞上 64 个三联体中的 3 个 stop 之一 → **截短**。
- 因此 frameshift 几乎总是产生**无功能蛋白**；这就是为什么许多严重遗传病(如部分囊性纤维化等位基因)由 indel 引起。
- 进一步：**3 倍数的 in-frame deletion** 例外——它**不移码**，只删去整数个氨基酸。
  - **囊性纤维化最常见的 ΔF508** 正是删去 **3 个碱基** → 删去**一个**苯丙氨酸(Phe508)，蛋白质错误折叠(本课 Section 4 详讲)。

> 🧠 一句话：**移不移码，看是不是 3 的倍数**；这是区分 indel 严重程度的关键判据。

## Misconceptions & Command Words（Section 1）

**易错点：**
- ❌ "所有突变都有害" → ✅ 突变可有害、**中性(silent)** 或极少数有利；多数是中性/被修复。
- ❌ "substitution 会移码" → ✅ 只有**插入/缺失**(非 3 倍数)才移码；替换数目不变，**不移码**。
- ❌ "一个碱基改变一定换氨基酸" → ✅ 因简并性可能 **silent**。
- ❌ 把 mutation 与 mutagen 混用 → ✅ mutagen 是**原因/因子**，mutation 是**结果**。

**命令词 Command Words：**
- **Describe** the effect of …：写出**碱基→密码子→氨基酸→蛋白质**这条链。
- **Explain** why a substitution may not change the protein：必须点名 **degenerate code / same amino acid**。

## Section 1 — Answers & Mark Points

**Q1 (3):** A deletion causes a **frameshift** (1); all triplets/codons **after** the deletion are read differently / reading frame shifts (1); so **many amino acids change** (and a premature stop may form), whereas a substitution changes **only one codon/amino acid** (1).

**Q2 (3):** **Silent** mutation (1); the code is **degenerate**, so the new triplet codes for the **same amino acid** (1); therefore the **amino-acid sequence is unchanged**, so protein structure/function is unchanged (1).

**Q3 (2):** Any two of: **UV / X-rays / gamma radiation** (ionising radiation); **tar in tobacco smoke / mustard gas / named chemical**; **certain viruses** (1 each, max 2).

> 📌 得分关键：Q2 必须出现 **degenerate** 与 **same amino acid** 两个词。

## Mini-Summary（Section 1）✅

- Gene mutation = **change in DNA base sequence**；多发生在复制时。
- **Substitution**：silent（简并→同氨基酸）/ missense（换氨基酸）/ nonsense（→stop）。
- **Insertion/Deletion**：非 3 倍数 → **frameshift**，后续全改，常无功能；3 倍数 → 不移码。
- 影响取决于**位置、氨基酸性质改变、显隐性、细胞类型**。
- **Mutagens**：辐射、化学物(焦油)、某些病毒 → ↑突变率。
- 经典例：**sickle cell = missense substitution (Glu→Val)**。

# Section 2 🧩
# Patterns of Inheritance
# 遗传模式

本节预告：核心术语(gene/allele/genotype/phenotype/dominant/recessive/homo-/heterozygous/codominant)；monohybrid cross；**Edexcel 标准遗传图**与 Punnett square；表型比 3:1、1:1；codominance（ABO 血型）；test cross。

---

## 🪝 Hook：为什么后代会"像"又"不像"父母？

- 孟德尔(Gregor Mendel)用**豌豆**做了上万次杂交，发现性状以**离散单位**(后来叫 gene)遗传，而非"混合"。
- 一株紫花 × 一株白花，子一代(F₁)**全紫**；F₁ 自交，子二代(F₂)出现 **紫:白 ≈ 3:1**——白花"消失"又"回来"。
- 这背后是：每个性状由**一对等位基因**控制，配子里**只带一个**，受精时**重新组合**。
- 🤔 思考：3:1 这个神奇比例从哪来？本节用 **Punnett square** 一眼看穿。

> 🖼️ 图示：孟德尔豌豆杂交三代图：P(紫×白) → F₁(全紫) → F₂(3 紫 : 1 白)，下方标 "discrete units, not blending"。

## 必背术语①：gene / allele / locus

- **Gene 基因**：编码一条多肽/性状的 DNA 片段。
- **Allele 等位基因**：同一基因的**不同版本**（碱基序列略不同，常源于突变）。
- **Locus 位点**：基因在染色体上的**固定位置**；同源染色体在**相同位点**带等位基因。
- 二倍体每个基因有**两个**等位基因（父母各给一个）：可能相同或不同。
- 命名约定：同一基因的等位基因用**同一字母**的大/小写表示（如 A 与 a）。

> 🖼️ 图示：一对同源染色体并排，同一位点上一条带 A、一条带 a，标注 "homologous chromosomes, same locus, different alleles"。

---

## 必背术语②：genotype / phenotype

- **Genotype 基因型**：个体携带的**等位基因组合**（如 AA、Aa、aa）。
- **Phenotype 表型**：基因型与环境**共同**表现出的**可观察性状**（如花色、血型）。
- 关系：genotype + environment → phenotype（接 3C：基因与环境互作）。
- **Homozygous 纯合子**：两个等位基因**相同**（AA 或 aa）——"breeds true 纯系"。
- **Heterozygous 杂合子**：两个等位基因**不同**（Aa）。

> 🧠 记忆：**homo = same（同）**，**hetero = different（异）**；**-zygous** 来自 zygote(合子)。

---

## 必背术语③：dominant / recessive

- **Dominant 显性等位基因**：在杂合子(Aa)中也能**表现**其性状 → 用**大写**字母。
- **Recessive 隐性等位基因**：只有在**纯合(aa)** 时才表现 → 用**小写**字母。
- 所以杂合子 **Aa 的表型 = 显性表型**（隐性被"掩盖"，但仍存在并可遗传 → carrier）。
- **Carrier 携带者**：杂合子，表型正常但带一个隐性等位基因，可传给后代（隐性遗传病关键）。

| 基因型 Genotype | 名称 | 表型 Phenotype（以 A 显性为例）|
|---|---|---|
| AA | homozygous dominant | 显性性状 |
| Aa | heterozygous（carrier）| 显性性状 |
| aa | homozygous recessive | 隐性性状 |

> 🖼️ 图示：三个个体 AA/Aa/aa，前两个显示同样颜色(显性)，第三个显示隐性颜色。

## Monohybrid cross 单基因杂交：什么是它

- **Monohybrid cross 单基因(性状)杂交**：研究**一个**基因(一对等位基因)的遗传。
- 核心生物学原理：**减数分裂(meiosis)** 时同源染色体分开 → 每个**配子(gamete)** 只得到**一个**等位基因（孟德尔分离定律 segregation）。
- 受精时父母配子**随机结合** → 后代基因型由**组合概率**决定。
- 我们用 **genetic diagram + Punnett square** 把"配子如何组合"系统列出，从而预测**比例与概率**。
- 下一页给出 **Edexcel 要求的标准画法**——务必每一行都写全，否则丢"method mark"。

> 🖼️ 图示：一对同源染色体在减数分裂中分离，两个配子各带一个等位基因，下方箭头 "random fertilisation"。

## ⭐ Edexcel 遗传图标准画法（必须背！）

画**任何**遗传图都按这 **6 行**写全（缺行丢分）：

```
1. Key 图例:        A = ... (dominant) ;  a = ... (recessive)
2. Parental phenotypes 亲代表型:    e.g. tall      ×    dwarf
3. Parental genotypes  亲代基因型:        Aa        ×     aa
4. Gametes 配子(画圈):              (A) (a)    ×    (a) (a)
5. Offspring 子代(Punnett square):  见方格
6. Offspring ratio 子代比例:        1 tall : 1 dwarf
```

- **配子必须画圈** ⭕（Edexcel 惯例，强调它是单倍体生殖细胞）。
- **比例**与**表型对应**都要写；问概率时把比例转成分数/百分比。

> 🖼️ 图示：上述 6 行的模板卡，配子用圆圈框住，Punnett square 用 2×2 网格。

## worked example A：Aa × Aa → 3:1

亲代都是杂合(如 Aa 紫花 × Aa 紫花)：

```
Key: A = purple (dominant), a = white (recessive)
Parental phenotype:   purple        ×        purple
Parental genotype:      Aa          ×          Aa
Gametes:            (A) (a)         ×       (A) (a)

Punnett square:
            |   (A)   |   (a)
      ------+---------+--------
       (A)  |   AA    |   Aa
       (a)  |   Aa    |   aa

Offspring genotypes: 1 AA : 2 Aa : 1 aa
Offspring phenotypes: 3 purple : 1 white     →  ratio 3 : 1
```

- 概率：P(purple)=3/4=75%；P(white)=1/4=25%。
- 在**显性表型**中，纯合:杂合 = **1 : 2**（即 1/3 是 AA，2/3 是 Aa）——常考！

> 🖼️ 图示：填好的 2×2 Punnett 方格，3 格显紫、1 格显白。

## worked example B：Aa × aa → 1:1（这就是 test cross）

杂合 × 隐性纯合：

```
Key: A = purple (dominant), a = white (recessive)
Parental phenotype:   purple        ×        white
Parental genotype:      Aa          ×          aa
Gametes:            (A) (a)         ×       (a) (a)

Punnett square:
            |   (a)   |   (a)
      ------+---------+--------
       (A)  |   Aa    |   Aa
       (a)  |   aa    |   aa

Offspring genotypes: 2 Aa : 2 aa = 1 Aa : 1 aa
Offspring phenotypes: 1 purple : 1 white   →  ratio 1 : 1
```

- 概率：P(purple)=1/2=50%；P(white)=1/2=50%。
- 这正是 **test cross（测交）** 的逻辑(后面单独讲)：用 aa 去"试"出未知显性个体的基因型。

> 🖼️ 图示：2×2 方格，左列两格显紫(Aa)、右列两格显白(aa)。

## 表型比例速查：常见 monohybrid 结果

| 亲代基因型 Cross | 子代基因型比 | 子代表型比（A 显性）| P(显性) |
|---|---|---|---|
| AA × AA | all AA | all 显性 | 1 |
| AA × aa | all Aa | all 显性 | 1 |
| AA × Aa | 1 AA : 1 Aa | all 显性 | 1 |
| **Aa × Aa** | 1 AA : 2 Aa : 1 aa | **3 显性 : 1 隐性** | 3/4 |
| **Aa × aa** | 1 Aa : 1 aa | **1 显性 : 1 隐性** | 1/2 |
| aa × aa | all aa | all 隐性 | 0 |

> 🧠 两个"招牌比例"：**Aa×Aa → 3:1**，**Aa×aa → 1:1**。看到题里有这俩比例，立刻反推亲本基因型。

## Codominance 共显性：两个等位基因"都说话"

- **Codominance 共显性**：杂合子中**两个**等位基因**都完整表达**，表型**同时**显现两者(非中间型)。
- 与不完全显性(incomplete dominance, 表型为中间型)区别：codominance 是"两者都在"，不是"调和"。
- 命名约定：用**同一大写字母**带**上标**区分(因为两者都"显性"地表达)：如 $C^R$、$C^W$。
- 经典例：某些牛毛色 $C^R C^W$ = **roan**（红白毛**混杂并存**，不是粉色)。
- 最重要的例子是人的 **ABO 血型** → 下一页详解(同时涉及 multiple alleles)。

> 🖼️ 图示：红毛牛 × 白毛牛 → roan 牛(红白毛斑驳并存)，强调"both expressed, not blended"。

## ABO 血型：codominance + multiple alleles

- ABO 由**一个基因**控制，但有**三个等位基因(multiple alleles)**：$I^A$、$I^B$、$i$。
- 显隐关系：
  - $I^A$ 与 $I^B$ 互为 **codominant（共显性）**；
  - $I^A$ 与 $I^B$ 都对 $i$ **显性**（i 为隐性）。

| Genotype 基因型 | Blood group 血型(phenotype) |
|---|---|
| $I^A I^A$ 或 $I^A i$ | **A** |
| $I^B I^B$ 或 $I^B i$ | **B** |
| $I^A I^B$ | **AB**（A、B 抗原**都**表达 → codominance）|
| $i\,i$ | **O** |

> 🖼️ 图示：红细胞表面抗原图——A 型有 A 抗原、B 型有 B 抗原、AB 型两种都有、O 型都没有。

## worked example C（codominance）：A × B 可生出 O？

杂合 A 型 × 杂合 B 型：$I^A i \times I^B i$

```
Key: I^A = antigen A, I^B = antigen B (I^A,I^B codominant; both dominant to i)
Parental phenotype:    group A        ×        group B
Parental genotype:      I^A i         ×         I^B i
Gametes:            (I^A) (i)         ×      (I^B) (i)

Punnett square:
            |  (I^B)   |   (i)
      ------+----------+----------
     (I^A)  |  I^A I^B |   I^A i
      (i)   |  I^B i   |    i i

Offspring: I^A I^B : I^A i : I^B i : i i = 1 : 1 : 1 : 1
Phenotypes:   AB    :   A   :   B   :  O
```

- 表型比 **AB : A : B : O = 1 : 1 : 1 : 1**；每种概率 = 1/4 = 25%。
- 是的，两个非 O 父母**可以**生出 O 型孩子(若双方都带 i)。

> 🖼️ 图示：2×2 方格四格分别标 AB、A、B、O，配色四种。

## Test cross 测交：如何查出未知基因型

- 问题：一个显性表型个体，基因型是 **AA 还是 Aa**？外观看不出。
- **Test cross（测交）**：用 **homozygous recessive (aa)** 与之杂交，看子代表型。
- 解读子代：
  - 若子代**全为显性** → 被测个体很可能是 **AA**（AA×aa → 全 Aa 显性）。
  - 若子代出现**显性:隐性 = 1:1** → 被测个体是 **Aa**（Aa×aa → 1 Aa : 1 aa）。
- 为什么用 aa？因为 aa 只产生 a 配子，**不会掩盖**被测个体贡献的等位基因 → 子代表型**直接暴露**其基因型。

```
Unknown × aa :
  AA × aa → all Aa  → all dominant
  Aa × aa → 1 Aa : 1 aa → 1 dominant : 1 recessive
```

> 🖼️ 图示：决策树——测交后"全显性?"→AA；"出现隐性?"→Aa。

## A* Going Deeper：从配子概率到 product/sum rule

- Punnett square 本质是把**两个独立事件**(父配子 × 母配子)的概率组合起来。
- **Product rule（乘法）**：两独立事件**同时**发生 → 概率**相乘**。
  - 例：Aa×Aa 生出 aa = P(父给 a)×P(母给 a) = 1/2 × 1/2 = **1/4**。
- **Sum rule（加法）**：互斥事件中**任一**发生 → 概率**相加**。
  - 例：Aa×Aa 生出杂合 Aa = (父A母a) + (父a母A) = 1/4 + 1/4 = **1/2**。
- 多胎/多代题不用画大方格，用 product/sum 直接算更快(后面 Maths 模块练)。
- 条件概率提醒：题问"在显性表型中是 Aa 的概率"→ 答 **2/3**(因为 1AA:2Aa 里只看显性那 3 份)。

> 🧠 一句话：**"且"用乘，"或"用加**；条件概率要**只在符合条件的子集里**算。

## Misconceptions & Command Words（Section 2）

**易错点：**
- ❌ 配子里写两个等位基因(如写 "Aa") → ✅ 配子是**单倍体**，只带**一个**(画圈 ⓐ)。
- ❌ 把 codominance 当 incomplete dominance(中间型) → ✅ codominance 是**两者都表达**(AB 型同时有 A、B)。
- ❌ "3:1 一定出现" → ✅ 那是**大量后代的期望比**；小样本会偏离(所以需 χ² 检验)。
- ❌ 忘写 **key/图例** → ✅ Edexcel 遗传图**必须**先定义符号。

**命令词：**
- **Complete the genetic diagram** [n]：按 6 行写全，配子画圈、写比例。
- **Calculate the probability** that …：以**分数/百分比**作答，并写出推理(product/sum)。

# Section 3 ⚧
# Sex Linkage
# 性连锁

本节预告：性染色体(XX 女、XY 男)；X 连锁基因；男性为何更常受累(**hemizygous**)；携带者女性；完整遗传图(haemophilia / colour blindness)与期望比例。

---

## 🪝 Hook：为什么色盲和血友病几乎都是男生？

- **Red-green colour blindness（红绿色盲）** 与 **haemophilia（血友病）** 都**男性远多于女性**。
- 这不是巧合——这两个基因都位于 **X 染色体**上，而男性只有**一条** X。
- 维多利亚女王是血友病携带者，把致病等位基因传遍欧洲多个王室("royal disease")，几乎都在**王子**身上发病。
- 🤔 思考：为什么"少一条 X"会让男性如此"暴露"于隐性 X 连锁病？本节解码 **hemizygous**。

> 🖼️ 图示：欧洲王室家系简图，血友病只在男性方块中出现，女性圆圈多为携带者(半填充)。

---

## 性染色体：XX 与 XY

- 人有 **23 对**染色体：**22 对 autosomes（常染色体）** + **1 对 sex chromosomes（性染色体）**。
- **Female 女性 = XX**；**Male 男性 = XY**。
- **X 染色体较大**，携带**许多基因**(不止决定性别)；**Y 染色体很小**，基因很少(主要含 **SRY** 等决定男性发育的基因)。
- 关键不对称：**X 上的大多数基因在 Y 上没有对应等位基因** → 男性这些基因**只有一份**。
- 配子角度：母亲只给 X；父亲给 X(→女儿)或 Y(→儿子) → **是父亲的精子决定后代性别**。

> 🖼️ 图示：X 与 Y 染色体并排比大小，X 上标多个基因位点，Y 上只标 SRY；下方 XX→女、XY→男。

---

## X-linked genes 与 hemizygous

- **Sex-linked / X-linked gene（X 连锁基因）**：位于 **X 染色体**上、在 **Y 上无对应**等位基因的基因。
- 记法：把等位基因写成 **X 的上标**，如 $X^H$(正常)、$X^h$(致病)；Y 不带该基因，写作 **Y**。
- **Hemizygous（半合子）**：男性对 X 连锁基因**只有一个**等位基因(因为只有一条 X，Y 上没有配对) → 既非纯合也非杂合。
- **所以呢**：男性只要 X 上带一个**隐性致病**等位基因($X^h Y$)就**会发病**——没有第二条 X 来"掩盖"它。
- 女性需**两条** X 都带致病等位基因($X^h X^h$)才发病 → 故女性发病罕见，多为**携带者**($X^H X^h$)。

> 🖼️ 图示：男性 X^h Y(致病等位基因无对应、直接表达) vs 女性 X^H X^h(正常等位基因掩盖致病)，箭头标 "hemizygous → expressed"。

---

## 为什么男性更常受累（核心逻辑）

- 对一个 **X 连锁隐性**病：
  - 男性发病只需 **1 个**隐性等位基因($X^h Y$)。
  - 女性发病需 **2 个**隐性等位基因($X^h X^h$)。
- 在群体中，"碰到 1 个"远比"碰到 2 个一起"概率高 → 故**男性患病率 ≫ 女性**。
- 女性更可能是**carrier($X^H X^h$)**：表型正常但可把 $X^h$ 传给后代。
- 传递特点(系谱线索)：
  - **父亲不会把 X 连锁等位基因传给儿子**(给儿子的是 Y)；只传给**女儿**。
  - 患病男性的**所有女儿**都至少是**携带者**(必得他的 $X^h$)。

> 🧠 一句话：**男性只有一条 X，隐性等位基因无处躲 → 更易发病**。

---

## worked example D：携带者母 × 正常父（血友病）

最常考的情形：carrier mother $X^H X^h$ × normal father $X^H Y$

```
Key: X^H = normal allele, X^h = haemophilia allele (recessive), Y = no allele
Parental phenotype:  carrier female      ×      normal male
Parental genotype:     X^H X^h           ×        X^H Y
Gametes:            (X^H) (X^h)          ×      (X^H) (Y)

Punnett square:
            |  (X^H)     |   (Y)
     -------+------------+-----------
    (X^H)   | X^H X^H    |  X^H Y
    (X^h)   | X^H X^h    |  X^h Y

Offspring: X^H X^H : X^H X^h : X^H Y : X^h Y  = 1 : 1 : 1 : 1
Phenotypes: normal girl : carrier girl : normal boy : haemophiliac boy
```

- 概率：P(affected child)=**1/4**；在**儿子**中 P(affected)=**1/2**；女儿中一半是携带者。
- 女儿**永不**发病(因父亲给 $X^H$)；只有儿子可能发病。

> 🖼️ 图示：四格 Punnett，仅右下 $X^h Y$ 格标红(haemophiliac boy)。

## worked example E：携带者母 × 患病父

更"凶险"的情形：carrier mother $X^H X^h$ × affected father $X^h Y$

```
Key: X^H normal, X^h colour-blind allele (recessive), Y = no allele
Parental phenotype: carrier female   ×   colour-blind male
Parental genotype:    X^H X^h         ×       X^h Y
Gametes:           (X^H) (X^h)        ×      (X^h) (Y)

Punnett square:
            |  (X^h)      |   (Y)
     -------+-------------+-----------
    (X^H)   | X^H X^h     |  X^H Y
    (X^h)   | X^h X^h     |  X^h Y

Offspring: X^H X^h : X^h X^h : X^H Y : X^h Y = 1:1:1:1
Phenotypes: carrier girl : affected girl : normal boy : affected boy
```

- 现在**女儿也可能发病**($X^h X^h$)！P(affected child)=**1/2**。
- 关键对比：父亲患病时，**一半女儿患病**；父亲正常时，**女儿全不患病**——父亲的 X 决定女儿命运。

## A* Going Deeper：X-inactivation 与"为什么女携带者多正常"

- 女性每个细胞**随机失活一条 X**（**X-inactivation**，形成 Barr body）→ 剂量补偿，使 XX 与 XY 的 X 基因表达量大致相当。

# Section 4 🫁
# Cystic Fibrosis: A Genetic Disease
# 囊性纤维化（一种遗传病）

本节预告：**CFTR** 基因/蛋白(氯离子通道)；对肺/消化/生殖系统的影响(厚黏液)；**常染色体隐性**遗传；携带者父母的遗传图；患病后代概率。

---

## 🪝 Hook：为什么 CF 患儿的汗"很咸"？

- 老欧洲谚语："被亲吻时额头尝起来咸的孩子，活不长。" —— 这其实是 **cystic fibrosis（囊性纤维化, CF）** 的早期描述。
- CF 患者汗液**异常咸**(高 NaCl)，因为皮肤汗腺**无法把 Cl⁻ 重吸收**回去。
- 同一个分子缺陷，在肺、胰、肠、生殖道却表现为**黏稠分泌物**——一个蛋白，多个系统。
- 🤔 思考：一个**氯离子通道**坏掉，怎么会让黏液变稠、让人不孕？本节把 CFTR 讲透。

> 🖼️ 图示：一个孩子额头标"salty sweat"，旁边箭头连到肺/胰/肠的黏稠黏液图标。

---

## CFTR 基因与蛋白：一个氯离子通道

- CF 由 **CFTR 基因**(位于 **chromosome 7**，常染色体)突变引起。
- 正常 **CFTR 蛋白** = 上皮细胞**膜上的一个 chloride-ion channel（氯离子通道）**(也是一种载体/通道蛋白，synoptic 接 2A 膜运输)。
- 正常功能：把 **Cl⁻ 主动/被动转运出细胞** → Na⁺ 随之外移 → 水通过**渗透(osmosis)** 跟出 → 在上皮表面形成**稀薄、易流动的黏液层**。
- 最常见突变 **ΔF508**：缺失 3 个碱基(in-frame deletion) → 少一个 **phenylalanine(Phe508)** → CFTR **错误折叠**、无法到达细胞膜 → 通道缺失/失能。
- **所以呢**：Cl⁻ 出不去 → 水不外渗 → 上皮表面黏液**脱水、变稠**。

> 🖼️ 图示：上皮细胞膜上的 CFTR 通道，Cl⁻ 与水正常外移(左：稀黏液) vs ΔF508 通道缺失(右：水留在细胞内、表面黏液变厚)。

---

## 厚黏液的连锁后果（一个缺陷，多系统）

机制总链：**CFTR 缺陷 → Cl⁻ 不外移 → 水不外渗 → 黏液脱水变稠**。受累系统：

- **Lungs / 呼吸系统**：厚黏液堵塞 **bronchioles** → 难以咳出 → 细菌滋生、反复**肺部感染**、炎症、气体交换面受损、长期肺损伤。
- **Digestive / 消化系统**：胰管被厚黏液**堵塞** → 消化酶(lipase 等)无法到达小肠 → **食物消化/吸收不良**、营养不良；也可致**肠梗阻**。
- **Reproductive / 生殖系统**：
  - 男性：输精管(vas deferens)缺失/阻塞 → **不育(infertile)**。
  - 女性：宫颈黏液变稠 → 阻碍精子通过 → **生育力下降**。

> 🖼️ 图示：人体三系统拼图——肺(黏液堵小支气管)、胰(导管堵塞、酶受阻)、生殖道(精子被稠黏液阻挡)。

---

## CF 的遗传方式：autosomal recessive

- CF 是 **autosomal recessive（常染色体隐性）** 遗传：
  - **autosomal**：基因在常染色体(chr 7) → **男女患病机会相同**(与性别无关)。
  - **recessive**：需**两个**致病等位基因(纯合 ff)才发病。
- 记法：**F** = 正常(显性)，**f** = CF 等位基因(隐性)。
- 基因型↔表型：

| Genotype | 表型 |
|---|---|
| **FF** | 不患病(unaffected) |
| **Ff** | 不患病，但为 **carrier（携带者）** |
| **ff** | 患 CF（affected） |

- 关键：**carrier(Ff) 表型正常**却能遗传 f → 两个携带者父母可生出患儿。

> 🖼️ 图示：FF/Ff/ff 三个体，前两个正常(Ff 标"carrier")，第三个标"CF"。

---

## worked example F：两携带者父母 → 25% 患病

最经典 CF 遗传图：carrier × carrier ($Ff \times Ff$)

```
Key: F = normal allele (dominant), f = cystic fibrosis allele (recessive)
Parental phenotype:  carrier (unaffected)  ×  carrier (unaffected)
Parental genotype:        Ff               ×        Ff
Gametes:               (F) (f)             ×      (F) (f)

Punnett square:
           |  (F)   |   (f)
     ------+--------+--------
      (F)  |  FF    |   Ff
      (f)  |  Ff    |   ff

Offspring genotypes: 1 FF : 2 Ff : 1 ff
Phenotypes: 3 unaffected : 1 affected   (ratio 3 : 1)
```

- **P(affected, ff) = 1/4 = 25%**；P(carrier, Ff)=1/2=50%；P(unaffected)=3/4。
- **A\* 条件概率**：若已知孩子**未患病**，他/她是携带者的概率 = **2/3**(因为正常的 3 份里有 2 份是 Ff)。

> 🖼️ 图示：2×2 方格，3 格正常、1 格(ff)标红"CF"。

## worked example G：携带者 × 患者

若一方是患者(ff)、一方是携带者(Ff)：

```
Key: F = normal (dominant), f = CF allele (recessive)
Parental phenotype:  carrier      ×      affected (CF)
Parental genotype:     Ff          ×          ff
Gametes:            (F) (f)        ×       (f) (f)

Punnett square:
           |  (f)   |   (f)
     ------+--------+--------
      (F)  |  Ff    |   Ff
      (f)  |  ff    |   ff

Offspring: Ff : ff = 1 : 1
Phenotypes: unaffected (carrier) : affected = 1 : 1
```

- **P(affected) = 1/2 = 50%**；未患病的孩子**全部**是携带者(Ff)。
- 对比记忆：carrier×carrier → **1/4 患病**；carrier×affected → **1/2 患病**。

## CF 的治疗与管理（概览，benefit–risk 接 Section 5/1C）

- **目前无法根治**(遗传缺陷在每个细胞)，但可**管理症状、延长寿命**：
  - **Physiotherapy 物理排痰** + 体位引流：帮助清除肺部厚黏液。
  - **Antibiotics 抗生素**：控制反复肺部感染。
  - **Enzyme supplements 消化酶替代**(随餐服)：弥补胰酶不足，改善营养吸收。
  - **Bronchodilators / DNase（稀释黏液药）**：改善通气、降低黏液黏度。
  - 前沿：**gene therapy 基因治疗** 与 **CFTR modulators**(如针对 ΔF508 的小分子)——synoptic 接 8C 基因技术。
- 评价：这些手段**改善生活质量与寿命**，但**负担重、终身、不能治本**。

## A* Going Deeper：把 ΔF508 与 Section 1 的突变类型对上

- ΔF508 是**缺失(deletion)**，但缺的是**3 个碱基** → **不移码(in-frame)** → 只删去**一个氨基酸(Phe508)**。
- 这回扣 Section 1 的判据：**indel 是否移码，看是不是 3 的倍数**。
- 后果：少一个 Phe 使 CFTR 蛋白**折叠错误** → 被细胞**质检系统降解**、到不了膜 → 通道功能缺失。
- 这说明：即使"只少一个氨基酸"(看似温和)，若落在关键蛋白上、影响折叠，也可致严重疾病——**严重性看位置与功能，不只看改了几个氨基酸**。
- synoptic：CFTR 是**膜运输蛋白**(2A) + 由**基因表达**而来(2B) + 缺陷源于**突变**(2C Section 1) → 一题可贯通 Topic 2。

> 🧠 一句话：ΔF508 = **in-frame 3-base deletion → 少一个 Phe → 折叠错误 → 通道缺失**。

## 什么是 genetic screening？/ What & why

- **Genetic screening 基因筛查**：检测个体/胚胎/胎儿是否携带特定**等位基因或染色体异常**。
- 目的：
  - 识别**患病**个体(诊断)；识别**携带者**(carrier testing，如近亲或高危人群)。
  - 评估**生育风险**、为决策提供信息、指导治疗与管理。
- 类型概览(本节逐一展开)：
  - **Prenatal 产前**：amniocentesis、CVS(胎儿已在子宫内)。
  - **Preimplantation 植入前**：PGD(IVF 胚胎，植入前检测)。
  - **配套服务**：genetic counselling(遗传咨询)。

> 🖼️ 图示：筛查时间轴——胚胎(PGD)→ 孕早期(CVS)→ 孕中期(amniocentesis)→ 出生后(新生儿筛查)。

---

## Amniocentesis 羊膜穿刺

- **做什么**：用细针经孕妇腹壁抽取少量 **amniotic fluid（羊水）**，其中含**胎儿脱落细胞**。
- **何时(when)**：通常孕 **15–20 周**(孕中期)。
- **如何分析**：培养细胞 → 做 **karyotype（核型分析）** 查染色体数目/结构异常(如 Down's, trisomy 21)，或 DNA 分析查单基因病(如 CF)。
- **风险(risk)**：有约 **0.5–1%** 的**流产(miscarriage)** 风险(因穿刺)。
- 特点：做得**较晚** → 若选择终止妊娠则在更晚孕期进行(对孕妇负担更大)，但取样**细胞较多、结果较可靠**。

> 🖼️ 图示：子宫剖面，超声引导下细针穿过腹壁进入羊膜腔抽羊水(避开胎儿与胎盘)。

---

## Chorionic Villus Sampling (CVS) 绒毛取样

- **做什么**：取一小块 **chorionic villi（绒毛膜绒毛）** 组织(来自**胎盘**，与胎儿基因型相同)。
- **何时(when)**：通常孕 **10–13 周**(比羊穿**更早**)。
- **如何分析**：绒毛细胞可**更快**获得 DNA/核型结果(无需长时间培养)。
- **风险(risk)**：流产风险**略高**于羊穿(约 **1–2%**)。
- 特点：做得**早** → 更早获知结果、若终止可在更早孕期进行；但**流产风险略高**，且偶有取到胎盘嵌合体导致的判读问题。

> 🖼️ 图示：子宫剖面，导管经宫颈(或经腹)到达胎盘取绒毛组织。

---

## Amniocentesis vs CVS 对比（必背表）

| 项目 | **Amniocentesis** 羊膜穿刺 | **CVS** 绒毛取样 |
|---|---|---|
| 取样组织 | amniotic fluid（胎儿细胞）| chorionic villi（胎盘组织）|
| 时间 when | 较晚，**15–20 周** | 较早，**10–13 周** |
| 出结果速度 | 较慢(需培养) | **较快** |
| 流产风险 | 较低，**~0.5–1%** | 较高，**~1–2%** |
| 主要优点 | 风险较低、结果可靠 | **更早**得知、可早决策 |
| 主要缺点 | 较晚、决策时孕周大 | 流产风险**略高** |

> 🧠 记忆：**CVS 早(early) + 风险略高**；**Amnio 晚(later) + 风险略低**。"早换来略高风险"是核心权衡。

---

## Preimplantation Genetic Diagnosis (PGD) 植入前诊断

- 背景：结合 **IVF(in-vitro fertilisation, 体外受精)**——在胚胎**植入子宫之前**检测。
- 流程：IVF 产生多个胚胎 → 在 **8 细胞期**取 1–2 个细胞 → 做基因检测 → **只把不携带致病等位基因的胚胎**植入。
- 最大优点：**避免在妊娠后才面临终止妊娠的抉择**(因为是在植入前选择胚胎)。
- 局限/争议：需 IVF(费用高、对女性身体负担、成功率有限)；只能检测**已知**的特定突变；引发"**选择胚胎**"的伦理争论。
- 适用：已知有严重单基因病家族史的父母(如 CF、Huntington's)。

> 🖼️ 图示：IVF 多个胚胎排成一排，对每个做 DNA 检测，"健康"胚胎被选中植入子宫，其余不植入。

---

## Genetic counselling 遗传咨询

- **Genetic counselling 遗传咨询**：由专业人员向个体/家庭**提供信息与支持**，帮助理解遗传风险并**自主决策**。
- 内容：
  - 解释**遗传方式**与**复发风险**(如 carrier×carrier → 1/4)。
  - 说明可选的**检测**(carrier test、产前检测、PGD)及其利弊与风险。
  - 讨论结果的**含义与选择**(继续妊娠、终止、领养、PGD、不生育等)。
- 关键原则：**non-directive（非指导性）**——提供信息但**不替当事人做决定**，尊重其价值观与自主权。
- **所以呢**：咨询让决策**知情(informed)** 且**自愿(voluntary)**，是筛查伦理的重要保障。

> 🖼️ 图示：咨询桌前，咨询师展示家系图与概率，夫妇在权衡选项，旁注 "non-directive"。

## 伦理与社会议题（AO3 重点）

筛查带来的**收益**与**顾虑**——评价题要**两面**都写并给**结论**：

| 收益 Benefits | 顾虑 Concerns / Issues |
|---|---|
| 提供信息，帮助**知情决策** | 结果带来**焦虑/心理负担** |
| 可**提前准备**(医疗、心理、经济) | 部分检测有**流产风险**(amnio/CVS) |
| 高危家庭可借 **PGD** 避免患病 | 涉及**终止妊娠**的道德分歧 |
| 早诊断 → 早管理、改善预后 | 担忧滑向 **"designer babies"** / 优生学 |
| 减少终身受疾病折磨 | **隐私/歧视**(保险、就业)、检测**不平等获取** |

> 🧠 评价模板：先**正反各列证据**，再**权衡**(谁更重/对谁而言)，最后给**有条件的结论**(it depends on …)。

## A* Going Deeper：把"概率"放进"决策"

- 筛查的价值不仅是"阳/阴"，还要结合**先验风险**与检测的**误差**来解读。
- 例：carrier×carrier 的**先验**患病概率是 **1/4**；做产前诊断后可把概率更新为接近 0 或接近 1(诊断性检测)。
- 但**筛查(screening)** 与**诊断(diagnostic)** 不同：筛查给**风险等级**(可能有假阳/假阴)，常需后续**诊断性**检测(如 amnio)确认。
- 决策框架(AO3)：**风险大小 × 后果严重性 × 可干预性 × 个人价值观/风险×收益** → 没有"标准答案"，但要论证**自洽**。
- synoptic：连 1C 的 **benefit–risk / 相关 vs 因果**思维，可迁移到评价任何医学检测/干预。

> 🧠 一句话：基因筛查题考的是**用概率与证据做权衡**，而非记忆某个"正确选择"。

# Skills 🧮
# Maths & Data Skills
# 数学与数据技能

本模块：概率、比例、百分比的统一处理 + **chi-squared (χ²) 检验**完整流程(假设、公式、自由度、临界值、结论) + 数据分析三步法。

---

## Maths Skill 1：比例 ↔ 概率 ↔ 百分比

- 遗传图给的是**比例(ratio)**；考题常要**概率(probability)** 或**百分比(%)**——三者可互换。
- 转换：把比例各项相加作分母。
  - 3 purple : 1 white → P(purple)=3/4=**0.75=75%**；P(white)=1/4=**25%**。
  - 1:1:1:1 → 每项 = 1/4 = **25%**。
- 概率范围 **0–1**(或 0–100%)；一组互斥结果概率之和 = **1**。
- 表达规范：考试用**分数**(如 1/4)或**百分比**(25%)均可，写清楚即可。

> 🖼️ 图示：一个饼图把 3:1 切成 3/4 与 1/4，标 75% / 25%。

---

## Maths Skill 2：product rule 与 sum rule

- **Product rule（乘法，"且"）**：两个**独立**事件**同时**发生 → 概率**相乘**。
  - 例：Ff×Ff 连续生**两个**患儿 = 1/4 × 1/4 = **1/16**。
- **Sum rule（加法，"或"）**：**互斥**结果中**任一**发生 → 概率**相加**。
  - 例：Aa×Aa 后代是**显性**(AA 或 Aa) = 1/4 + 1/2 = **3/4**。
- 组合题示范：Ff×Ff，求"**恰好**两个孩子中**一个**患病" = (患·正) + (正·患) = (1/4×3/4)+(3/4×1/4) = 3/16 + 3/16 = **6/16 = 3/8**。

> 🧠 一句话：看到"and/both"想**乘**，看到"or/either"想**加**；"恰好一个"= 把两种顺序**加**起来。

---

## Maths Skill 3：条件概率（A\* 高频）

- 条件概率 = 在**已知某条件**下的概率 → **缩小分母**到符合条件的子集。
- 招牌例 ①：Aa×Aa 的显性后代中，**纯合(AA)** 占多少？
  - 显性后代 = 1 AA : 2 Aa → P(AA | dominant) = **1/3**；P(Aa | dominant) = **2/3**。
- 招牌例 ②：CF carrier×carrier，**未患病**孩子是携带者概率？
  - 未患病 = 1 FF : 2 Ff → P(carrier | unaffected) = **2/3**。
- 招牌例 ③：X 连锁 carrier 母×正常父，**儿子**患病概率？
  - 只在**儿子**($X^H Y$, $X^h Y$)里算 → **1/2**(而 P(child affected)=1/4)。

> 🖼️ 图示：把 1:2:1 的四格中"患病"那格划掉，剩 3 格里数 Ff 占 2 格 → 2/3。

---

## Maths Skill 4：chi-squared (χ²) 检验 — 用途与假设

- **何时用**：检验**类别(分类)数据**的**观察值(O)** 是否与某遗传假说预测的**期望值(E)** 显著不同(如 3:1、1:1、9:3:3:1)。
- **Null hypothesis $H_0$**：观察比例与期望比例**没有显著差异**(差异仅由**随机机遇 chance** 造成)。
- 公式：
$$\chi^2 = \sum \frac{(O-E)^2}{E}$$
- 其中 $O$ = observed(实测个体数)，$E$ = expected(按假设比例算的个体数)。
- ⚠️ 必须用**实际个数(counts)**，**不能用百分比/比例**代入！

> 🧠 直觉：$(O-E)^2$ 衡量偏差大小，除以 $E$ 做"相对化"；偏差越大 → χ² 越大 → 越可能**拒绝** $H_0$。

---

## Maths Skill 5：χ² 的自由度与临界值

- **Degrees of freedom（自由度）**：$df = (\text{类别数 categories}) - 1$。
  - 3:1 → 2 类 → **df = 1**；9:3:3:1 → 4 类 → **df = 3**。
- 在 **p = 0.05** 显著性水平查**临界值(critical value)** 表：

| df | critical value (p = 0.05) |
|---|---|
| 1 | **3.84** |
| 2 | 5.99 |
| 3 | **7.81** |
| 4 | 9.49 |

- **判读规则**：
  - 若 **χ² < 临界值** → 差异**不显著** → **接受(retain) $H_0$**(偏差可由 chance 解释，与假设一致)。
  - 若 **χ² ≥ 临界值** → 差异**显著** → **拒绝 $H_0$**(偏差不太可能只是机遇，假设可能不成立)。

> 🧠 记忆：**df=1 → 3.84**(单基因 3:1/1:1 题最常用)；**df=3 → 7.81**(双基因 9:3:3:1)。

---

## Maths Skill 6：χ² 完整 worked example（接受 $H_0$）

**情境**：一株玉米杂交预期 **3 purple : 1 yellow**。实得 **200** 粒：**156 purple, 44 yellow**。问：数据是否支持 3:1？(p=0.05)

**Step 1 — $H_0$**：observed ratio 与 3:1 无显著差异(差异由 chance)。
**Step 2 — 算 E**：总数 200，比例 3:1 → E(purple)=200×3/4=**150**；E(yellow)=200×1/4=**50**。
**Step 3 — 列表算 $\frac{(O-E)^2}{E}$**：

| Category | O | E | O−E | (O−E)² | (O−E)²/E |
|---|---|---|---|---|---|
| Purple | 156 | 150 | +6 | 36 | 0.24 |
| Yellow | 44 | 50 | −6 | 36 | 0.72 |
| | | | | **χ² =** | **0.96** |

---

## Maths Skill 6（续）：得出结论的"标准句"

- **Step 4 — df**：2 类 → df = 2 − 1 = **1**。
- **Step 5 — 临界值**：df=1, p=0.05 → **3.84**。
- **Step 6 — 比较与结论**：
  - χ² = **0.96 < 3.84** → 差异**不显著**。
  - **Conclusion（标准句）**：*"χ² (0.96) is less than the critical value (3.84) at p = 0.05, so we accept the null hypothesis: there is no significant difference between observed and expected, and the results are consistent with a 3 : 1 ratio. Any difference is due to chance."*

> 📌 写结论必须含三要素：**比较(χ² vs 临界值)** + **接受/拒绝 $H_0$** + **生物学解读(是否符合预期比例)**。

---

## Maths Skill 7：χ² 反例（拒绝 $H_0$）+ 易错点

- 同样玉米题，若实得 **132 purple : 68 yellow**(仍 200 粒)：
  - E 仍为 150 : 50。
  - Purple：(132−150)²/150 = 324/150 = **2.16**；Yellow：(68−50)²/50 = 324/50 = **6.48**。
  - **χ² = 8.64**，df=1，临界值 3.84。
  - 8.64 **> 3.84** → 差异**显著** → **拒绝 $H_0$**：结果与 3:1 **不一致**，偏差**不太可能**只是机遇(需找其他解释)。
- **χ² 常见失分点**：
  - ❌ 代入**百分比/比例**(必须用**个数**)；❌ 忘记**平方**或忘记**除以 E**。
  - ❌ df 用了类别数(应是**类别数−1**)；❌ 结论只说数字不说"接受/拒绝 $H_0$"。

> 🧠 同样 ±18 的偏差(132/68)就显著，而 ±6(156/44)不显著——**偏差越大、样本越能放大它 → χ² 越大**。

---

## 数据分析示范：describe — quote — explain（三步法）

**给定数据**(某 X 连锁病家系统计)：1000 名男性中 80 人患病；1000 名女性中 4 人患病。**Describe and explain**。

- **Describe（描述趋势 + 引数据）**：The condition is **far more common in males** — **80/1000 (8%)** males are affected compared with only **4/1000 (0.4%)** females（约 **20 倍**）。
- **Quote（引用对比数据）**：already embedded（8% vs 0.4%）—记得**带数字**。
- **Explain（机制）**：the allele is **X-linked recessive**; males are **hemizygous**, so **one** recessive allele causes the condition; females need **two** recessive alleles, which is much rarer → hence the large sex difference.

> 🧠 三步法口诀：**先描述(带数据) → 再引对比 → 后解释机制**；data-response 题每步各占分。

## Exam Practice — MCQ ×5（先做，后看解析）

1. A substitution mutation changes a codon from GAA to GAG; both code for glutamic acid. This is best described as:
 **A** missense **B** nonsense **C** silent **D** frameshift
2. The deletion of **two** bases from the middle of a gene will most likely cause:
 **A** a silent mutation **B** a frameshift **C** loss of one amino acid only **D** no change
3. In rabbits, B (black) is dominant to b (brown). A cross gives 1 black : 1 brown. The parents' genotypes are:
 **A** BB × bb **B** Bb × Bb **C** Bb × bb **D** BB × Bb
4. A colour-blind man (X-linked recessive) has a daughter with a woman homozygous for the normal allele. The daughter is:
 **A** affected **B** a carrier **C** unaffected and not a carrier **D** XY
5. For a χ² test on a 9 : 3 : 3 : 1 ratio, the degrees of freedom and critical value (p=0.05) are:
 **A** 3 and 7.81 **B** 4 and 9.49 **C** 1 and 3.84 **D** 3 and 5.99

---

## MCQ — Answers & Distractor Analysis (1/2)

**Q1 → C (silent).** 同一氨基酸(Glu)未变 → silent。
- A missense 需**换**氨基酸；B nonsense 需变 stop；D frameshift 需 indel(此处是替换，数目不变)。✘

**Q2 → B (frameshift).** 删 **2** 个碱基(非 3 倍数) → 阅读框后移 → frameshift。
- A silent 是替换且氨基酸不变；C "loss of one amino acid only" 需删 **3** 个碱基(in-frame)；D "no change" 显然错。✘

**Q3 → C (Bb × bb).** 1:1 是**测交比**(杂合×隐性纯合)。
- A BB×bb → 全黑(Bb)；B Bb×Bb → 3:1；D BB×Bb → 全黑。✘

> 📌 看到 **1:1 想 Bb×bb**，**3:1 想 Bb×Bb**——比例反推基因型是高频技巧。

---

## MCQ — Answers & Distractor Analysis (2/2)

**Q4 → B (a carrier).** 父 $X^b Y$、母 $X^B X^B$ → 女儿必得父的 $X^b$ 与母的 $X^B$ → $X^B X^b$ = **carrier**。
- A affected 需 $X^b X^b$(母无 $X^b$)；C 不可能(女儿必得父 $X^b$)；D 女儿是 XX 不是 XY。✘

**Q5 → A (3 and 7.81).** 9:3:3:1 有 **4** 类 → df = 4−1 = **3**；df=3, p=0.05 临界值 = **7.81**。
- B 9.49 是 df=4；C 是 df=1(2 类)；D 5.99 是 df=2。✘

> 📌 χ² 题先数**类别数**→ df=类别数−1 → 再查临界值；**df=1→3.84, df=3→7.81** 必背。

## Exam Practice — Structured Q1（基因突变，data-response）

**Q1.** 下表为某蛋白一段 mRNA 与对应氨基酸，以及两个突变体：

| | Codons (mRNA) | 氨基酸序列 |
|---|---|---|
| Normal | AUG – GAA – CGU – UUA | Met – Glu – Arg – Leu |
| Mutant 1 | AUG – GAG – CGU – UUA | Met – Glu – Arg – Leu |
| Mutant 2 | AUG – G**U**A – CGU – UUA | Met – Val – Arg – Leu |

(a) Name the **type** of mutation in Mutant 1 and **explain**, using the term *degenerate*, why the protein is unchanged. **[3]**
(b) Name the **type** of mutation in Mutant 2 and **explain** why it may affect the protein's function. **[3]**
(c) Explain why a **single base deletion** in this gene would probably have a **greater** effect than either mutation shown. **[3]**

⏱️ 10 分钟。先写类型，再写**因果链**。

---

## Structured Q1 — Mark Scheme

**(a) [3]:** **Silent** (substitution) (1); GAA→GAG, but the code is **degenerate** so both code for the **same amino acid (glutamic acid)** (1); the **amino-acid sequence is unchanged**, so protein structure/function is unaffected (1).

**(b) [3]:** **Missense** (substitution) (1); the codon now codes for a **different amino acid (Glu→Val)** (1); this may **change the protein's 3-D shape / tertiary structure** (e.g. altering bonding/folding), so its function (e.g. as an enzyme/channel) may be lost (1).

**(c) [3]:** A single-base deletion causes a **frameshift** (1); **all** codons **downstream** are read in a different frame (1); so **many amino acids change** (and a premature stop codon may form), giving a non-functional protein — a far greater effect than a one-amino-acid change (1).

> 📌 (a)(b) 都要**先命名类型再解释**；(c) 关键词 **frameshift + downstream + premature stop**。

## Exam Practice — Structured Q2（性连锁，完整遗传图）

**Q2.** Haemophilia is caused by an X-linked recessive allele ($X^h$). A woman who is a **carrier** marries a man who is **unaffected**.

(a) Define the term **carrier**. **[1]**
(b) **Construct** a full genetic diagram to show this cross, including a key, parental genotypes, gametes and offspring. **[4]**
(c) **State** the ratio of phenotypes expected in the offspring. **[1]**
(d) **Calculate** the probability that, if the couple have a **son**, he will have haemophilia. **[1]**
(e) **Explain** why none of their **daughters** will have haemophilia. **[2]**

⏱️ 12 分钟。配子画圈、男性写 Y、表型分性别。

---

## Structured Q2 — Mark Scheme (1/2)

**(a) [1]:** A carrier is an individual who is **heterozygous** and carries **one copy of the recessive (disease) allele** but does **not** show the condition (phenotypically normal) (1).

**(b) [4]:**

```
Key: X^H = normal allele, X^h = haemophilia allele (recessive), Y = no allele
Parental phenotype:  carrier female   ×   unaffected male
Parental genotype:     X^H X^h         ×       X^H Y
Gametes:            (X^H) (X^h)        ×      (X^H) (Y)

Punnett square:
           |  (X^H)    |   (Y)
    -------+-----------+----------
   (X^H)   | X^H X^H   |  X^H Y
   (X^h)   | X^H X^h   |  X^h Y
```

Marks: key (1); parental genotypes correct incl. **Y** (1); gametes correct in **circles** (1); offspring genotypes correct in Punnett square (1).

---

## Structured Q2 — Mark Scheme (2/2)

**(c) [1]:** Offspring phenotypes = **normal female : carrier female : normal male : haemophiliac male = 1 : 1 : 1 : 1** (1). *(Acceptable also: 1 normal female : 1 carrier female : 1 normal male : 1 affected male.)*

**(d) [1]:** Among **sons** ($X^H Y$ and $X^h Y$), one of two is affected → **probability = 1/2 (50%)** (1).
*(注意：P(any child affected)=1/4，但题问 son → 分母只算儿子。)*

**(e) [2]:** Every daughter receives an $X^H$ from her **father** (his only X carries the normal allele) (1); so the **maximum** any daughter can be is a **carrier ($X^H X^h$)**, never $X^h X^h$, so no daughter is affected (1).

> 📌 (e) 灵魂句："daughters get the father's $X^H$" → 至多是携带者。

## Exam Practice — Structured Q3（囊性纤维化 + 卡方）

**Q3.** Cystic fibrosis (CF) is autosomal recessive (F = normal, f = CF allele).

(a) Two carrier parents have children. **Construct** a genetic diagram and **state** the probability that a child has CF. **[4]**

(b) A geneticist studies **240** offspring from many such (Ff × Ff) crosses and records **165 unaffected : 75 affected**. The expected ratio is 3 : 1. Carry out a **chi-squared test** (p = 0.05) to decide whether the results differ significantly from 3 : 1. Show all working, the degrees of freedom, the critical value, and your conclusion. **[6]**

⏱️ 15 分钟。χ² 用**个数**、列表、写**df + 临界值 + 结论三要素**。

---

## Structured Q3 — Mark Scheme (a)

**(a) [4]:**

```
Key: F = normal allele (dominant), f = CF allele (recessive)
Parental phenotype:  carrier      ×      carrier
Parental genotype:     Ff          ×        Ff
Gametes:            (F) (f)        ×      (F) (f)

Punnett square:
           |  (F)   |   (f)
     ------+--------+--------
      (F)  |  FF    |   Ff
      (f)  |  Ff    |   ff

Offspring: 1 FF : 2 Ff : 1 ff
```

Marks: key (1); parental genotypes + gametes in **circles** (1); Punnett square / 1 FF : 2 Ff : 1 ff (1); **P(CF) = 1/4 = 25%** (the ff outcome) (1).

---

## Structured Q3 — Mark Scheme (b)

**(b) [6]:**
- **$H_0$**: no significant difference between observed and expected (3:1); any difference is due to chance (1).
- **Expected**: total 240 → E(unaffected)=240×3/4=**180**; E(affected)=240×1/4=**60** (1).
- **Calculation table** (1 for correct method, 1 for correct χ²):

| Category | O | E | (O−E)² | (O−E)²/E |
|---|---|---|---|---|
| Unaffected | 165 | 180 | 225 | 1.25 |
| Affected | 75 | 60 | 225 | 3.75 |
| | | | **χ² =** | **5.00** |

- **df** = 2 − 1 = **1**; **critical value** at p=0.05 = **3.84** (1).
- **Conclusion**: χ² (5.00) **> 3.84**, so the difference **is significant** → **reject $H_0$**: the results **differ significantly** from a 3:1 ratio (the deviation is unlikely to be due to chance alone) (1).

> 📌 注意此例 **拒绝** $H_0$！结论必须含 **比较 + 拒绝 $H_0$ + 生物学解读**。

## A* 答题技巧总结 / A* Exam Technique

- **遗传图**：永远写全 **6 行**(key → 亲表型 → 亲基因型 → 配子(画圈) → Punnett → 比例)；漏行=漏分。
- **性连锁**：男性写 **Y**；配子两种；表型**分性别**；"son/daughter"题改**分母**。
- **概率**："且×、或+"；条件概率**只在子集**算(2/3、1/2 等)。
- **突变题**：先**命名类型**，再走**碱基→密码子→氨基酸→蛋白质**因果链；解释 silent 必提 **degenerate**。
- **χ²**：用**个数**、列表、df=类别−1、查临界值、结论**三要素**(比较+接受/拒绝 $H_0$+生物学含义)。
- **评价题(筛查)**：正反**各列证据 + 权衡 + 有条件结论**。

> 🧠 一句话：A\* = **机制写到底 + 计算不出错 + 评价两面 + 术语对版**。

## 高频失分点 Top Pitfalls

- ❌ 配子写两个等位基因 / 不画圈 → 失 method mark。
- ❌ substitution 说成会移码；frameshift 说成只改一个氨基酸。
- ❌ 解释 silent 不提 **degenerate / same amino acid**。
- ❌ 男性基因型漏 Y；"son 概率"用了全部子代当分母。
- ❌ 把 CF 当性连锁；说 carrier 会发病；条件概率忘排除患病项(应 2/3)。
- ❌ χ² 代入百分比 / 忘平方或忘除 E / df 用类别数 / 结论只报数字。
- ❌ amnio 与 CVS 时间组织记反；评价题只写一面。
