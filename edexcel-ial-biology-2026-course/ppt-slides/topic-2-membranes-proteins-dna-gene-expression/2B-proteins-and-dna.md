# Section 1 🔑
# Enzymes
# 酶：生物催化剂

本节预告：什么是酶；activation energy 的降低；active site 与 enzyme–substrate complex；**lock-and-key vs induced-fit**；intracellular vs extracellular；specificity 的结构基础。

---

## 🪝 Hook：为什么生牛排在体温下不会"自己消化"，吃下去却能被分解？

- 蛋白质、淀粉在**体温 (37°C)** 下放着几乎**不反应**——化学上太慢。
- 可一旦进入消化道，几分钟内就被**酶 (enzymes)** 快速分解。
- 工业上分解纤维素需要**强酸 + 高温**；而牛胃里的微生物酶在**温和条件**下就能办到。
- 🤔 同一个反应，为什么"加了酶"就能在温和条件下飞速进行？
- 答案藏在一个词：**activation energy（活化能）**——以及一块能精准"咬合"底物的 **active site**。

> 🖼️ 图示：左为一块生牛排在常温下"沉睡"(慢)，右为同一块肉遇到酶图标后被迅速剪成小段(快)，中间一个大写的 "$E_a$↓"。

---

## 什么是酶？Enzymes as Biological Catalysts

- **Enzyme（酶）**：由活细胞产生的 **biological catalyst（生物催化剂）**，能**加快反应速率 (speed up the rate of reaction)** 而**自身不被永久改变 (not used up / unchanged)**。
- 因为不被消耗 → 一个酶分子可**反复使用**，**少量**即可催化**大量**底物。
- 几乎所有酶都是 **globular protein（球状蛋白）**：折叠紧凑、可溶、有精确 3D 形状。
- 酶**降低活化能**，但**不改变反应的方向或平衡位置 (does not change ΔG / equilibrium position)**——只让平衡**更快**达到。

> 🖼️ 图示：一个球状酶反复"夹住底物→放出产物→再夹下一个"，循环箭头标 "reused; not used up"。

---

## 活化能 Activation Energy（核心！）

- 任何反应都要先翻过一道"能量山坡"——**activation energy ($E_a$, 活化能)**：使反应物达到**过渡态 (transition state)** 所需的最小能量。
- 没有酶：只有少数分子能量够高 → 反应**很慢**。
- 有酶：酶**降低 $E_a$ (lowers the activation energy)** → 在**同样温度**下，**更多分子**能越过这道更矮的坡 → 反应**加快**。
- ⭐ 关键澄清：酶**不是给反应"加能量"**，而是把"门槛"降低。

> 🖼️ 图示：反应进程-能量曲线。两条峰：高峰(无酶, $E_a$ 大)与矮峰(有酶, $E_a$ 小)；起点(反应物)与终点(产物)的能量**完全相同**，只是中间峰被压低，标 "enzyme lowers $E_a$, ΔG unchanged"。

---

## Active Site 与 Enzyme–Substrate Complex

- **Substrate（底物）**：酶作用的反应物。
- **Active site（活性位点）**：酶分子表面一个**特定形状**的凹槽，由少数氨基酸 R 基构成，**与底物形状互补 (complementary)**。
- 底物结合到 active site → 形成 **enzyme–substrate complex（酶–底物复合物, ES complex）**。
- 反应发生后 → 形成 **enzyme–product complex** → 产物离开 → 酶**恢复原状**，再接下一个底物。
- ⭐ active site 的形状由酶的 **tertiary structure（三级结构）** 决定——这把 1A 与本课连起来。

> 🖼️ 图示：球状酶上一个凹槽(active site)，底物像拼图一样嵌入 → "ES complex" → 反应 → 产物弹出 → 酶复原。

---

## 酶如何降低活化能？机制 Mechanism

酶降低 $E_a$ 的几种方式（理解即可）：

- **正确取向 (orientation)**：把底物以**最有利的角度**固定 → 反应基团对准。
- **施加张力 (straining bonds)**：诱导契合时酶轻微改变底物形状 → **拉伸/扭曲底物的键** → 更易断裂。
- **提供微环境 (microenvironment)**：active site 内的 R 基可提供合适的电荷/pH，稳定**过渡态**。
- **拉近反应物 (proximity)**：把两个底物拉到一起 → 增大有效碰撞概率。
- **所以呢**：以上都让"翻越能量山坡"变容易 → $E_a$ 下降 → 速率上升。

> 🖼️ 图示：active site 内两个底物被夹近、被轻微扭曲，键处出现"张力"标记；旁注 "stabilises transition state"。

---

## 模型①：Lock-and-Key 锁钥模型

- **Lock-and-key model（锁钥模型）**：active site 形状与底物**精确、刚性地互补**——像**钥匙(底物)** 插进**锁(酶)**。
- 只有**形状匹配**的底物能进入 → 解释了**specificity（专一性）**。
- 优点：直观，正确抓住了"形状互补 + 专一"。
- 局限：把 active site 当作**固定不变**的刚性结构——但实验显示 active site 在结合时会**轻微改变形状**（见下一页）。

> 🖼️ 图示：一把钥匙(底物)恰好插入一把锁(酶 active site)，形状严丝合缝，标 "rigid, exact fit"。

---

## 模型②：Induced-Fit 诱导契合模型（更准确）

- **Induced-fit model（诱导契合模型）**：active site 起初**不是完全互补**；底物靠近时，酶的 active site **轻微改变形状 (changes shape / moulds around substrate)**，以**更紧密地包裹底物**。
- 这一形变会**对底物的键施加张力 (puts strain on the substrate's bonds)** → 降低 $E_a$ → 反应更快。
- 产物形状不再匹配 → active site 恢复原状，释放产物。
- ⭐ 现代普遍接受 **induced-fit** 更准确：它解释了"形状如何主动帮助催化"，而不仅是被动匹配。

> 🖼️ 图示：底物接近 → active site"张开/合拢"包住它(形变箭头) → 底物键被拉伸 → 产物释出后 active site 回弹复原。

---

## Lock-and-Key vs Induced-Fit 对比

| | **Lock-and-key** | **Induced-fit** |
|---|---|---|
| active site 形状 | **刚性、固定**，已与底物精确互补 | **可微调**，结合时改变形状去包裹底物 |
| 结合过程 | 底物直接"插入" | 底物**诱导** active site 改变形状 |
| 对底物键 | 不强调施力 | **施加张力**，主动降低 $E_a$ |
| 解释专一性 | 可以（靠形状匹配） | 可以（且更完整） |
| 现状 | 较早、较简化 | **更被接受**、更准确 |

> 📌 一句话：**锁钥**说"形状要对"；**诱导契合**说"形状会动着去对，并帮忙催化"。

---

## Intracellular vs Extracellular 酶

- **Intracellular enzymes（胞内酶）**：在**产生它们的细胞内部**起作用。
  - 例：**catalase（过氧化氢酶）** 在细胞内分解有毒的 $H_2O_2$；呼吸/光合途径中的酶；DNA polymerase。
- **Extracellular enzymes（胞外酶）**：被细胞**分泌到细胞外**起作用。
  - 例：消化酶 **amylase（淀粉酶）、protease（蛋白酶）、lipase（脂肪酶）** 在消化道腔内分解食物大分子；真菌/细菌分泌酶到体外消化基质再吸收。
- **所以呢**：大分子食物太大无法进入细胞 → 必须先由**胞外酶在体外水解**成小分子，才能吸收。

> 🖼️ 图示：左为一个细胞内 catalase 把 $H_2O_2 → H_2O + O_2$（intracellular）；右为细胞向外分泌 amylase，在肠腔把淀粉切成麦芽糖（extracellular）。

---

## Catalase 实例：胞内酶的重要性

- 代谢副产物 **hydrogen peroxide ($H_2O_2$)** 有毒，会损伤细胞。
- **Catalase（过氧化氢酶）** 催化其分解：$2H_2O_2 \rightarrow 2H_2O + O_2$。
- catalase 是**极快**的酶之一（每秒可分解数万个 $H_2O_2$）→ 防止 $H_2O_2$ 积累。
- 实验上很常用：把肝/马铃薯组织放入 $H_2O_2$，**冒出的 $O_2$ 气泡/泡沫**就是 catalase 活性的可测指标（见 Core Practical）。
- ⭐ 这正是本课核心实验最常用的酶之一——记牢它的反应式。

> 🖼️ 图示：一块肝组织放入 $H_2O_2$ 试管，剧烈冒泡，气体导入排水量筒收集 $O_2$，标 "rate of O₂ = enzyme activity"。

## Enzyme Specificity 专一性

- **Specificity（专一性）**：一种酶通常**只催化一种(或一类)反应 / 只作用于一种特定底物**。
- 结构基础：只有**形状与 active site 互补**的底物才能结合形成 ES complex。
- active site 的形状由**特定的氨基酸序列 (primary structure) → 折叠出的 tertiary structure** 决定。
- **所以呢**：序列由基因决定 → 基因决定酶的形状 → 决定它"认得"哪个底物（呼应本课后半 DNA→蛋白）。
- 类比：每把锁(酶)只配一把钥匙(底物)。

> 🖼️ 图示：一个酶面对三种不同形状的底物，只有形状互补的那个能嵌入 active site，另两个被挡在外面(打叉)。

| Induced-fit | 诱导契合模型 | active site 结合时改变形状包裹底物 |

## A\* 深化：为什么"诱导契合"能更好解释催化？

- 锁钥只说"形状互补"，但解释不了：**为什么结合后反应会变快**。
- 诱导契合补上关键一环：active site 改变形状 → **对底物键施加张力 (strain)** → 把底物推向**过渡态** → **降低 $E_a$**。
- 进一步：active site 还能为过渡态提供**稳定的微环境**（特定电荷/极性的 R 基）。
- 🎯 高分写法：被问"用 induced-fit 解释酶如何加快反应"时，务必写到 **"active site changes shape → strains/distorts substrate bonds → lowers activation energy"**——这是拿满分的链条。
- 进阶：抑制剂、变性都通过**改变 active site 形状**起作用——后面 Section 2 会反复用到这一点。

> 🖼️ 图示：诱导契合三连——①底物入坞 ②active site 收拢+底物键被拉伸(高亮张力) ③越过被压低的能垒释放产物。

## 易错点 & 命令词 — Section 1

**常见错误 Misconceptions：**
- ❌ 说酶"提供能量 / 降低反应物能量"——酶只**降低 $E_a$**，反应物与产物能量不变。
- ❌ 说酶"被反应消耗"——酶**不被消耗**，可反复使用。
- ❌ 把 active site 说成"整个酶分子"——只是**一小块特定凹槽**。
- ❌ 只写"shape complementary"却不提**tertiary structure**——A\* 要点链断了。
- ❌ 把 induced-fit 说成"底物改变形状去适应酶"——是**酶(active site)改变形状去包裹底物**。

**命令词 Command Words：**
- **Describe** how an enzyme works = active site + complementary + ES complex + lowers $E_a$。
- **Compare** lock-and-key vs induced-fit = 用并行句写"rigid vs changes shape / passive vs strains substrate"。

## Mini-Summary — Section 1 ✅

- 酶 = **biological catalyst**：降低 **activation energy**，自身**不被消耗**，是 **globular protein**。
- **Active site**（形状由 tertiary structure 决定）与底物**互补** → 形成 **ES complex**。
- **Lock-and-key**（刚性精确互补）vs **induced-fit**（active site 改变形状、施加张力，更准确）。
- **Intracellular**（如 catalase）vs **extracellular**（如 amylase）。
- **Specificity** 源于 active site 形状的互补性 → 最终由基因/序列决定。
- 🧠 锚点："形状互补 → ES complex → 降 $E_a$ → 反应快。"

# Section 2 ⚙️
# How Enzymes Work
# 酶如何工作：影响因素与抑制

本节预告：温度($Q_{10}$/最适/变性)、pH、底物浓度($V_{max}$/饱和)、酶浓度；competitive vs non-competitive inhibitors；initial rate；**Core Practical** 与速率计算。

---

## 🪝 Hook：发烧到 42°C 为什么有生命危险？

- 人体酶的**最适温度 (optimum)** 约 **37°C**；体温稍高时反应更快，可一旦超过约 **40–42°C**……
- 酶开始**变性 (denature)**——形状被破坏，**永久失去活性**。
- 关键代谢(呼吸等)的酶一旦失效 → 细胞功能崩溃 → 危及生命。
- 同理：洗衣粉里的**生物酶 (biological detergent)** 在温水里去污最佳，水太烫反而失效。

## 如何测"酶活性"= 反应速率 Rate of Reaction

- "酶活性"通常用**反应速率 (rate of reaction)** 衡量：
  - **底物消失的速率**（如淀粉减少），或
  - **产物生成的速率**（如 $O_2$ 气体体积、颜色变化）。
- $$\text{rate} = \frac{\text{change in quantity}}{\text{time}}$$
- 常见测量：单位时间内产生的**气体体积** $\text{cm}^3\,\text{s}^{-1}$、**颜色变化所需时间**(如碘液变色)、pH/吸光度变化。
- ⭐ 越快达到终点 / 单位时间产物越多 → 速率越高 → 酶越活跃。

> 🖼️ 图示：三种测量法并列——量筒收集 $O_2$、比色计测吸光度、秒表计"碘液不再变蓝"的时间。

## 因素①：Temperature 温度（升温段）

- **升温**：分子获得更多**动能 (kinetic energy)** → 运动更快 → 酶与底物**碰撞更频繁、更有效 (more frequent successful collisions)** → 更易形成 ES complex → 速率上升。
- 经验规律：在变性前，**温度每升高 10°C，速率约翻倍**（见下页 $Q_{10}$）。
- 直到 **optimum temperature（最适温度）**，速率达到最高。
- ⭐ 注意：升温**只在最适温度以前**有利；超过就走向变性。

> 🖼️ 图示：速率-温度曲线的**上升段**，箭头标 "↑KE → ↑successful collisions"；峰顶标 "optimum"。

---

## 温度系数 $Q_{10}$（数学技能）

- **Temperature coefficient $Q_{10}$（温度系数）**：温度升高 **10°C** 时速率增加的倍数。
- $$Q_{10} = \frac{\text{rate at }(T+10)}{\text{rate at }T}$$
- 多数酶反应在变性前 $Q_{10} \approx 2$（即升 10°C 速率约**翻倍**）。
- **例题：** 20°C 时速率 $= 4.0$，30°C 时速率 $= 8.0$。
  - $Q_{10} = \dfrac{8.0}{4.0} = \textbf{2.0}$。
- ⚠️ 解读：$Q_{10}$ 须取**相同温差(10°C)**的两点；接近/超过最适温度时 $Q_{10}$ 会下降（变性抵消了升温）。

> 🖼️ 图示：曲线上 20°C 与 30°C 两点，竖线读出 4.0 与 8.0，旁边算式 $Q_{10}=8/4=2$。

---

## 因素①：Temperature 温度（降速/变性段）

- 超过 **optimum** 后继续升温：过多热能使**维持三级结构的弱键（hydrogen / ionic bonds）断裂**。
- 酶分子**形状改变 → active site 形状改变** → 底物**不再互补** → 不能形成 ES complex → 速率**骤降**。
- 这叫 **denaturation（变性）**：通常是**不可逆 (permanent)** 的（共价的 peptide bond 不断，但 3D 形状回不来）。
- **低温**：分子动能低 → 碰撞少 → 速率慢，但酶**未变性**（只是"休眠"），回温可恢复活性。

> 🖼️ 图示：完整折叠的酶 →(高温)→ 弱键断裂、链松散摊开、active site 走样；标 "H-bonds/ionic bonds break → active site changes → denatured"。

---

## 因素②：pH

- 每种酶有一个 **optimum pH（最适 pH）**（如多数 ~7；胃蛋白酶 pepsin ~2；肠道酶 ~8）。
- 偏离最适 pH：过多/过少的 **$H^+$** 会干扰 active site 及底物的**电荷**，破坏维持三级结构的 **hydrogen bonds 与 ionic bonds**。
- → active site **形状改变** → 与底物不再互补 → 速率下降。
- 极端 pH → **denaturation（变性，通常不可逆）**。
- ⭐ 因果链与温度过高类似：**改变电荷/断弱键 → active site 变形 → 失去互补**。

> 🖼️ 图示：钟形 pH-速率曲线，峰在最适 pH；两侧标 "ionic/H-bonds disrupted → active site changes shape"。

---

## 因素③：Substrate Concentration 底物浓度

- **低底物浓度**：底物是**限制因素 (limiting factor)** → 增加底物 → 更多 ES complex → 速率**成比例上升**。
- 继续增加 → 越来越多 active site 被占用。
- 到某点：**所有 active site 都在忙 (all active sites occupied/saturated)** → 速率达到**最大值 $V_{max}$**，不再上升。
- 此时**酶浓度(active site 数)** 成了新的限制因素。
- ⭐ 曲线形状：先线性上升 → 渐缓 → **plateau（平台，$V_{max}$）**。

> 🖼️ 图示：速率-底物浓度曲线，先陡升后变平；平台处标 "$V_{max}$ — all active sites saturated"。

---

## 因素④：Enzyme Concentration 酶浓度

- 在**底物充足**的前提下：增加酶浓度 → 更多 **active sites** 可用 → 更多 ES complex → 速率**成比例上升**。
- 若底物有限：增加酶到一定程度后，**底物成为限制因素** → 速率不再上升(平台)。
- 对比记忆：
  - **底物浓度↑**：受 **active site 总数**(酶量)封顶 → $V_{max}$。
  - **酶浓度↑**：受 **底物总量**封顶。
- ⭐ 永远先判断"**谁是 limiting factor**"。

> 🖼️ 图示：左图"底物充足时"酶浓度-速率呈正比直线；右图"底物有限时"上升后变平。

## 因素小结：四条曲线对照

| 因素 ↑ | 曲线形状 | 限制因素 / 关键点 |
|---|---|---|
| **Temperature** | 升→峰(optimum)→骤降 | 升温↑碰撞；过高→变性 |
| **pH** | 钟形，峰在最适 pH | 偏离→断弱键→变性 |
| **Substrate conc.** | 升→平台 $V_{max}$ | 饱和时受**酶量**限制 |
| **Enzyme conc.** | (底物足)正比直线 | 否则受**底物量**限制 |

> 📌 答题口诀：温度/pH 偏离 → **denature（active site 变形）**；浓度类 → 先判 **limiting factor**，再决定是否到 **plateau**。

## Initial Rate of Reaction 初始反应速率（重点！）

- 反应进行中，**底物被消耗** → 速率会逐渐**变慢**(曲线变平)。
- 因此比较不同条件时，要用 **initial rate（初始速率）**——反应**刚开始 (t = 0)** 时的速率，此时底物最充足、最能反映该条件下酶的真实活性。
- 测法：在 **time = 0** 处对产物-时间曲线作**切线 (tangent)**，算切线**梯度 (gradient)**。
- ⭐ 为什么用初始速率：起点处**底物浓度最高、产物抑制最小** → 公平比较各条件。

> 🖼️ 图示：产物-时间曲线起点处画一条切线，标 "initial rate = gradient of tangent at t = 0"；曲线后段渐平标 "substrate running out"。

---

## 数学技能：从图算速率（梯度 gradient）

**线性段直接算梯度：**
- $$\text{rate} = \text{gradient} = \frac{\Delta y}{\Delta x} = \frac{\text{change in product}}{\text{change in time}}$$

**例题：** 一条 $O_2$ 体积-时间图，线性段在 0–20 s 内 $O_2$ 由 $0$ 升到 $24\ \text{cm}^3$。
- $\text{rate} = \dfrac{24 - 0}{20 - 0} = \textbf{1.2}\ \text{cm}^3\,\text{s}^{-1}$。

**初始速率(曲线)用切线：** 在 $t=0$ 作切线，取切线上两点(如 $(0,0)$ 与 $(10,30)$)：
- $\text{initial rate} = \dfrac{30 - 0}{10 - 0} = \textbf{3.0}\ \text{cm}^3\,\text{s}^{-1}$。

> 🖼️ 图示：曲线 + 起点切线，标出切线上两读数点与"上升/水平"直角三角形。

---

## 数学技能：百分比变化 Percentage Change

- $$\%\ \text{change} = \frac{\text{final} - \text{initial}}{\text{initial}} \times 100$$
- **例题：** pH 7 时速率 $= 2.5\ \text{cm}^3\,\text{s}^{-1}$，pH 5 时降为 $1.5\ \text{cm}^3\,\text{s}^{-1}$。百分比变化？
  - $\dfrac{1.5 - 2.5}{2.5}\times 100 = \dfrac{-1.0}{2.5}\times 100 = \textbf{-40\%}$（下降 40%）。
- ⚠️ 注意正负号：负号代表**减少**；分母永远是 **initial(起始/对照)** 值。

> 🖼️ 图示：两根柱(2.5 与 1.5)，箭头标 "↓40%"，旁列公式与代入。

## 抑制剂 Inhibitors：总览

- **Inhibitor（抑制剂）**：降低酶活性(反应速率)的分子。
- 两大类（按"在哪结合"分）：
  - **Competitive（竞争性）**：结合在 **active site**，与底物**竞争**。
  - **Non-competitive（非竞争性）**：结合在 **active site 以外的另一个位点 (allosteric site)**。
- 又按"能否被移除"分：
  - **Reversible（可逆）**：靠弱键结合，可解离。
  - **Irreversible（不可逆）**：靠共价键牢固结合(如重金属、某些毒物)，永久失活。
- ⭐ 抑制剂的本质：**改变/占据 active site，使底物无法正常结合或被催化**。

> 🖼️ 图示：左 competitive 分子坐在 active site 里挡住底物；右 non-competitive 分子坐在别处、却让 active site 变形。

---

## Competitive Inhibitor 竞争性抑制剂

- 形状**与底物相似 (similar shape to substrate)** → 能进入并占据 **active site**。
- 与底物**竞争** active site → 占着时底物无法结合 → 速率下降。
- **可被高底物浓度逆转 (overcome by increasing substrate concentration)**：底物多了，更可能"抢回" active site。
- 因此：竞争性抑制**不改变 $V_{max}$**（底物足够多时仍可达 $V_{max}$），只是**达到 $V_{max}$ 需要更多底物**。
- 例：**malonate** 抑制 succinate dehydrogenase（与 succinate 竞争）。

> 🖼️ 图示：底物与抑制剂排队争抢同一个 active site；速率-底物浓度图上"加抑制剂"曲线右移但最终仍达同一 $V_{max}$。

---

## Non-competitive Inhibitor 非竞争性抑制剂

- 结合在 **active site 以外的位点 (allosteric site)**。
- 结合后使酶**改变形状 → active site 形状改变** → 底物**不能再正常结合/催化** → 速率下降。
- **不能靠增加底物逆转**（因为问题不在"抢 active site"，而在"active site 已变形")。
- 因此：非竞争性抑制**降低 $V_{max}$**（无论多少底物都达不到原来的最高速率）。
- 例：许多**重金属离子(如 $Hg^{2+}$、$Ag^+$)** 是不可逆的非竞争性抑制剂。

> 🖼️ 图示：抑制剂结合在别处→酶整体形变→active site 走样；速率-底物浓度图上"加抑制剂"曲线整体压低，$V_{max}$ 下降。

---

## Competitive vs Non-competitive 对比

| | **Competitive 竞争性** | **Non-competitive 非竞争性** |
|---|---|---|
| 结合位点 | **active site**（与底物同） | **active site 以外**(allosteric) |
| 形状 | 与**底物相似** | 不必与底物相似 |
| 对 active site | 暂时占据 | 使其**改变形状** |
| 增加底物能否逆转 | **能**（高底物可克服） | **不能** |
| 对 $V_{max}$ | **不变**（只是更难达到） | **降低** |

> 📌 一句话：**竞争性 = 抢座位**（多来底物可赶走它，$V_{max}$ 不变）；**非竞争性 = 砸坏座位**（座位变形，$V_{max}$ 降）。

---

## 可逆 vs 不可逆抑制

- **Reversible inhibition（可逆抑制）**：抑制剂靠**弱键**(氢键/离子键)结合，可**解离** → 酶活性可恢复。多数竞争性、部分非竞争性属此类。
- **Irreversible inhibition（不可逆抑制）**：抑制剂靠**共价键**牢固结合，**不能解离** → 酶永久失活。
  - 例：**重金属(Hg²⁺/Pb²⁺)、有机磷农药/神经毒剂(抑制 acetylcholinesterase)、青霉素(抑制细菌转肽酶)**。
- 生理意义：许多**药物 (drugs)** 正是设计成酶抑制剂（如阿司匹林、他汀、抗生素）。
- ⭐ 抑制并非全是坏事——是重要的**代谢调控**和**药物作用**机制。

> 🖼️ 图示：左 reversible(虚线弱键，双向箭头可脱离)；右 irreversible(实线共价键，单向锁死)。

## 🧪 Core Practical：温度对 catalase 活性的影响

**原理：** $2H_2O_2 \xrightarrow{\text{catalase}} 2H_2O + O_2$；**测产生 $O_2$ 的速率** = 酶活性。

**测量方法（任选其一）：**
- 用排水法/气体注射器收集单位时间 $O_2$ **体积** $(\text{cm}^3\,\text{s}^{-1})$；或
- 测一定时间内**滤纸片浮起**的时间(catalase 浸渍法)；或
- 测固定体积 $O_2$ 产生所需**时间**(取倒数 $1/t$ 作速率)。

## Core Practical：变量与方法细节

**Independent variable 自变量：** temperature（如 10, 20, 30, 40, 50°C，用 **water bath** 控温）。
**Dependent variable 因变量：** rate of $O_2$ production $(\text{cm}^3\,\text{s}^{-1})$（或 $1/t$）。
**Control variables 控制变量（公平实验）：**
- $H_2O_2$ **浓度与体积**、酶**来源/浓度/体积**(如同一批马铃薯打浆)、**pH**(用 buffer)、组织**表面积**、总反应**时间窗**。

**提高可靠性：** 每个温度**重复 3 次取平均**；**先把酶与底物分别预热到设定温度**再混合；同一时刻开始计时。

## Core Practical：结果、处理与评价

**典型结果(描述)：** rate 随温度上升而增加，到约 **optimum(~40°C)** 达峰，之后因 **denaturation** 急剧下降。
**数据处理：**
- 用 $1/t$ 或 $V/t$ 计算速率 → 绘 **rate vs temperature** 曲线 → 找 optimum。
- 可算两点 $Q_{10}$（变性前段）。

**Risk assessment 风险评估：**
- $H_2O_2$ **腐蚀性/刺激性** → 戴 **goggles**、手套；浓度勿过高。
- 高温水浴**烫伤** → 小心操作；玻璃器皿轻拿。

**评价 Evaluation（常考）：** $O_2$ 收集**起始气泡**误差 → 用气体注射器更准；温度在反应中**漂移** → 用恒温槽；**初始速率**(切线)比终点法更公平。

## 易错点 & 命令词 — Section 2

**常见错误 Misconceptions：**
- ❌ 说"高温把酶**杀死/killed**"——酶不是活的；正确词是 **denatured**。
- ❌ 把 denaturation 说成"可逆"——温度/pH 过度通常**不可逆**(共价键不断但 3D 形状回不来)。
- ❌ 底物浓度图平台说成"底物用完"——是 **active sites 饱和(saturated)**。
- ❌ 把竞争性抑制对 $V_{max}$ 的影响搞反——竞争性 **$V_{max}$ 不变**；非竞争性 **$V_{max}$ 降**。
- ❌ 比较条件时用**终点**而非 **initial rate**。

**命令词 Command Words：**
- **Explain** the effect of temperature/pH = 写到 **kinetic energy / collisions** 或 **denaturation(断弱键→active site 变形)**。
- **Calculate** rate/$Q_{10}$/% change = **带单位、看有效数字、看正负号**。

## 答案与评分点 — Section 2 (1/2)

**Q1 [3]:** 1) (molecules gain) more **kinetic energy** / move faster; 2) more **frequent successful collisions** between enzyme and substrate; 3) more **enzyme–substrate complexes** form per second → rate increases. (each ✓)

**Q2 [3]:** 1) above optimum, **hydrogen bonds / ionic bonds** (holding tertiary structure) **break**; 2) enzyme/**active site changes shape (denatures)**; 3) substrate **no longer complementary / cannot bind** → fewer ES complexes → rate falls. (each ✓)

**Q3 [2]:** $Q_{10} = \dfrac{3.0}{1.5}$ ✓ $= \textbf{2.0}$ ✓ (no units).

---

## 答案与评分点 — Section 2 (2/2)

**Q4 [4]:** competitive: 1) **similar shape to substrate**, binds **active site**; 2) can be **overcome by increasing substrate concentration** → **$V_{max}$ unchanged**. non-competitive: 3) binds **elsewhere (not active site)**, **changes active site shape**; 4) **not** overcome by more substrate → **$V_{max}$ lowered**. (each ✓)

**Q5 [2]:** 1) at the start **substrate concentration is highest / not yet limiting** (and least product inhibition); 2) so it gives a **fair comparison** of the true rate before substrate runs out / curve flattens. (each ✓)

**Q6 [2]:** 1) **all active sites are occupied/saturated** with substrate; 2) adding more substrate cannot increase rate → enzyme concentration now limiting → $V_{max}$. (each ✓)

> 💡 得分关键：变性题必含 "active site changes shape → not complementary"；$Q_{10}$ 无单位。

## Mini-Summary — Section 2 ✅

- **Temperature**↑：↑KE→↑successful collisions→↑rate，到 optimum；超过→**denature**(断弱键→active site 变形)。$Q_{10}$ 多≈2。
- **pH** 偏离最适→断 H/ionic bonds→active site 变形→变性。
- **Substrate conc.**↑→升到 **$V_{max}$**(active sites 饱和)；**enzyme conc.**↑(底物足)→正比。
- **Competitive**(占 active site，高底物可克服，**$V_{max}$ 不变**) vs **Non-competitive**(结合别处使 active site 变形，**$V_{max}$ 降**)；reversible/irreversible。
- 比较条件用 **initial rate = 切线梯度**。
- 🧠 锚点："偏离条件→active site 变形→失互补；浓度类→先判 limiting factor。"

# Section 3 🧬
# The Structure of DNA and RNA
# DNA 与 RNA 的结构

本节预告：nucleotide(戊糖+磷酸+碱基)；purines(A,G) vs pyrimidines(C,T,U)；phosphodiester bond；sugar–phosphate backbone；antiparallel；complementary base pairing(**A–T 2 键、C–G 3 键**)；double helix；DNA vs RNA(mRNA/tRNA/rRNA)。

---

## 🪝 Hook：4 个"字母"如何写下一整个生命？

- 你的每个细胞里都有约 **2 米长**的 DNA，却只用 **4 种碱基 (A, T, C, G)** 拼写。
- 这 4 个字母的**排列顺序**编码了你所有蛋白质的氨基酸序列——决定你是谁。
- DNA 还能被**精确复制**(传给子细胞)、并被**读取**(指导蛋白质合成)。
- 🤔 一个分子如何同时做到：**稳定储存、精确复制、可被读取**？
- 答案藏在它优雅的**双螺旋 + 互补配对**结构里——本节解码。

> 🖼️ 图示：细胞核中盘绕的 DNA 拉直成长长的双螺旋"梯子"，梯级标 A-T / C-G，旁注 "4 letters → all of life"。

---

## 核苷酸 Nucleotide：核酸的单体

- **Nucleotide（核苷酸）** = 核酸 (DNA/RNA) 的**单体**，由 **3 部分**缩合而成：
  1. **Pentose sugar（五碳糖）**：DNA 用 **deoxyribose**，RNA 用 **ribose**。
  2. **Phosphate group（磷酸基团）**：带负电、酸性。
  3. **Nitrogenous base（含氮碱基）**：A / T(或 U) / C / G 之一。
- 三部分由 **condensation reactions** 连接(脱水成键)。
- ⭐ DNA/RNA 都是 **polynucleotide（多核苷酸）**——核苷酸长链。

> 🖼️ 图示：一个核苷酸的"三件套"——五边形糖居中，磷酸接在糖的一侧，碱基接在另一侧；标 "sugar + phosphate + base"。

---

## 碱基 Bases：嘌呤 vs 嘧啶

- **Purines（嘌呤）= 双环结构**：**Adenine (A) 腺嘌呤**、**Guanine (G) 鸟嘌呤**。
- **Pyrimidines（嘧啶）= 单环结构**：**Cytosine (C) 胞嘧啶**、**Thymine (T) 胸腺嘧啶**、**Uracil (U) 尿嘧啶**。
- **DNA 的碱基**：A, T, C, G。
- **RNA 的碱基**：A, **U**, C, G（用 **uracil 取代 thymine**）。
- ⭐ 记忆法：**"Pure As Gold"**（**Pur**ines = **A**、**G**）；其余(C, T, U)是嘧啶。
- ⭐ 配对永远是 **嘌呤(双环) 配 嘧啶(单环)** → 保证双螺旋**宽度恒定**。

> 🖼️ 图示：左栏双环的 A、G(标 purine)，右栏单环的 C、T、U(标 pyrimidine)；箭头标 "purine + pyrimidine = constant width"。

---

## 磷酸二酯键与糖–磷酸骨架

- 相邻核苷酸通过 **condensation** 连接：一个核苷酸糖的 **C3** 与下一个核苷酸的 **phosphate(连在 C5)** 之间形成 **phosphodiester bond（磷酸二酯键）**。
- 由此交替的 **sugar–phosphate backbone（糖–磷酸骨架）** 沿链延伸；**碱基**向内伸出。
- 每条链有方向：一端是 **5′ (5-prime)**(自由磷酸端)，另一端是 **3′ (3-prime)**(自由 −OH 端)。
- ⭐ 骨架由**共价的磷酸二酯键**连接 → **强、稳定**，保护内侧碱基(遗传信息)。

> 🖼️ 图示：一条链上糖(五边形)与磷酸(圆)交替相连，连接处标 "phosphodiester bond"；两端标 5′ 与 3′；碱基朝内伸出。

---

## 互补碱基配对 Complementary Base Pairing（必背！）

- 两条多核苷酸链由内侧碱基间的 **hydrogen bonds** 配对连接，规则**严格固定**：
  - **A pairs with T**（A–T），由 **2 个 hydrogen bonds** 连接。
  - **C pairs with G**（C–G），由 **3 个 hydrogen bonds** 连接。
- (RNA 中 A 配 **U**，仍是 2 个氢键。)
- 这叫 **complementary base pairing（互补碱基配对）**。
- ⭐ 必背口诀：**"A–T 二，C–G 三"**；**"购物三件 → C–G 3 bonds"**(C、G 字母圆鼓鼓，记 3)。

> 🖼️ 图示：两条骨架间，A=T 之间画 2 条虚线、C≡G 之间画 3 条虚线；红字标 "A–T: 2 H-bonds; C–G: 3 H-bonds"。

---

## 反平行双链 Antiparallel Strands

- DNA 的两条链**方向相反 (antiparallel)**：一条 **5′→3′**，另一条 **3′→5′**。
- 它们的碱基互补配对，像一架"梯子"：
  - **两侧**= 糖–磷酸骨架(梯子的"边")。
  - **梯级**= 互补碱基对(由氢键连接)。
- 整架梯子**扭成 double helix（双螺旋）**(Watson & Crick, 1953)。
- ⭐ 反平行很重要：它决定了复制时两条新链合成方向相反(2C/更高阶会用)。

> 🖼️ 图示：两条骨架一条标 5′→3′(向上)、另一条 3′→5′(向下)，中间互补碱基相连，整体右旋成螺旋。

---

## 为什么 C–G 比 A–T "更稳"？（A\* 衔接）

- **C–G 有 3 个 hydrogen bonds**，**A–T 只有 2 个** → C–G 配对**更强、更稳定**。
- **所以呢**：**GC 含量高**的 DNA 区段，两链更难被拉开 → **更稳定、解链温度更高**。
- 这解释了实验现象：高 GC 含量的 DNA 需要**更高温度**才能"熔解(变性)"分开两链。
- ⭐ 又一次体现"**多而弱的氢键，靠数量决定强度**"(呼应 1A)。

> 🖼️ 图示：两段 DNA，一段富 A–T(2 键，易拉开)、一段富 C–G(3 键，难拉开)；温度计显示后者熔解温度更高。

## 数学技能：Chargaff's Rule 碱基比例计算

- **Chargaff's rule（查戈夫法则）**：双链 DNA 中 **%A = %T** 且 **%C = %G**(因互补配对)。
- 推论：**%A + %G = %C + %T = 50%**；**(A+G) = (C+T)**(嘌呤总量=嘧啶总量)。
- **例题 1：** 某 DNA 含 **20% A**。求 T、C、G 各占多少？
  - %T = %A = **20%**；A+T = 40% → C+G = 60% → %C = %G = **30%** each。
- **例题 2：** 若 $\dfrac{A}{T}=1$ 且 A = 28%，则 G = ?
  - A=T=28% → A+T=56% → C+G=44% → **G = 22%**(C 也 22%)。
- ⚠️ 仅适用**双链 DNA**；单链 RNA / 单链 DNA **不成立**。

> 🖼️ 图示：饼图 A=T=20%、C=G=30% 拼成 100%；旁列 "%A=%T, %C=%G" 法则。

# Section 4 🔁
# How DNA Works (Replication)
# DNA 如何工作：半保留复制

本节预告：semi-conservative replication；helicase 解旋、DNA polymerase、互补配对；**Meselson–Stahl** 实验(密度梯度、¹⁵N/¹⁴N)如何证明半保留；为何不是 conservative / dispersive。

---

## 🪝 Hook：一个细胞分裂前，2 米 DNA 如何被"无误"地复制成两份？

- 细胞分裂(mitosis)前，必须把全部 DNA **完整、精确**复制一份，让两个子细胞各得一套。
- 人类基因组约 **30 亿**碱基对——复制几乎**零差错**，靠的是什么机制？
- 关键在于 **互补配对**：每条旧链都能当"模板"指导新链。
- 🤔 但新 DNA 里，"旧"与"新"链如何分布？1958 年一个经典实验给出了优雅证明。
- 本节：先讲**机制**，再讲 **Meselson–Stahl** 如何**用密度**区分三种假说。

> 🖼️ 图示：一条双螺旋"拉开拉链"，两侧旧链各自指导合成一条新链，最终变成两条相同的双螺旋。

---

## 半保留复制 Semi-conservative Replication：概念

- **Semi-conservative replication（半保留复制）**：每条新 DNA 分子由**一条原有的(旧)链 + 一条新合成的链**组成。
- "semi-conservative" = **一半保留**(保留了一条母链)。
- 这保证子代 DNA 与母代**碱基序列一致** → 遗传信息**精确传递**。
- 对照(将在 M–S 实验中被排除)：
  - **Conservative（全保留）**：母双链完整保留，全新双链另成一份。
  - **Dispersive（弥散）**：新旧片段**混杂**在每条链上。

> 🖼️ 图示：三联示意——semi(每分子一旧一新)、conservative(一全旧一全新)、dispersive(每链斑驳新旧相间)，用不同颜色区分新/旧链。

---

## 复制机制（步骤 1）：解旋 Unwinding

- 酶 **DNA helicase（解旋酶）** 移动到 DNA 上，**打断碱基间的 hydrogen bonds**。
- 两条链被**解开、分离 (unwound and separated)** → 形成"复制叉"，露出单链**模板 (template strands)**。
- 因为氢键**弱、可逆** → 才能被酶在常温下打开(再次呼应"多而弱"的设计)。
- ⭐ 注意：helicase 断的是**氢键**，**不是**共价的磷酸二酯键(骨架保持完整)。

> 🖼️ 图示：helicase 像"拉链头"沿 DNA 前进，把双链拆成两条单链(氢键断裂的虚线消失)，露出碱基。

---

## 复制机制（步骤 2）：配对与连接

- 周围游离的 **DNA nucleotides** 按 **complementary base pairing** 与每条模板链的碱基配对(A–T, C–G)，先以**氢键**结合。
- 酶 **DNA polymerase（DNA 聚合酶）** 把相邻核苷酸的糖–磷酸**用 phosphodiester bonds 连接**成新链。
- 每条模板各指导合成一条新的互补链 → 得到**两条**双链，每条 = **一旧 + 一新**。
- ⭐ 因模板互补 → 新链序列**精确复制**了原序列。

> 🖼️ 图示：两条模板链上，游离核苷酸按 A-T/C-G 对位嵌入，DNA polymerase 把它们"缝合"成连续新链；标 "free nucleotides → base pair → polymerase joins (phosphodiester)"。

---

## 复制所需的关键"零件"清单

| 组件 Component | 作用 Role |
|---|---|
| **DNA helicase** | 打断**氢键**、解开双链，分出两条模板 |
| **Template strands** | 旧链作模板，按互补规则指导新链 |
| **Free DNA nucleotides** | 原料，按 A–T/C–G 与模板配对 |
| **DNA polymerase** | 用 **phosphodiester bonds** 把核苷酸连成新链 |
| **Complementary base pairing** | 保证新链序列**精确**复制 |

> 📌 一句话流程：**helicase 解旋(断氢键) → 游离核苷酸互补配对 → DNA polymerase 连接(成键)**。

---

## 为什么半保留复制"高保真"？

- 每条**旧链都是模板** → 新链由**互补规则**精确决定 → 子代序列与母代**一致**。
- 子细胞各得**一条母链**作为"参照" → 减少累积错误。
- DNA polymerase 还有**校对 (proofreading)** 功能(超纲了解)：发现错配可纠正 → 误差极低。
- **所以呢**：遗传信息能**稳定地代代相传**——这是遗传的分子基础。

> 🖼️ 图示：母链(蓝)指导新链(红)，每个碱基"对号入座"；旁注 "old strand = template → accurate copy"。

---

## Meselson–Stahl 实验：要证明什么？

- 1958 年，**Meselson 和 Stahl** 设计实验来区分三种假说：**semi-conservative / conservative / dispersive**。
- **核心思路**：用**重/轻氮同位素**给 DNA"称重"，再用**密度梯度离心**按密度分层，看新 DNA 落在哪条带。
- 两种氮同位素：
  - **¹⁵N（重氮）**：使 DNA 密度**高**。
  - **¹⁴N（轻氮）**：使 DNA 密度**低**。
- ⭐ 关键：DNA 含 N(碱基里) → 用哪种 N 合成，就决定 DNA 的"重量(密度)"。

> 🖼️ 图示：两支离心管，重 DNA(¹⁵N)沉在管底偏下，轻 DNA(¹⁴N)停在偏上；标 "density-gradient centrifugation"。

---

## Meselson–Stahl：实验步骤

1. 细菌(E. coli)在含 **¹⁵N** 的培养基中长很多代 → 所有 DNA 都是**重的(¹⁵N/¹⁵N)**。
2. 把细菌**转移到只含 ¹⁴N** 的培养基中，让其**复制**。
3. 在**第 1 代、第 2 代**取样，提取 DNA，做**density-gradient centrifugation(密度梯度离心)**。
4. 看 DNA 形成的**条带位置(密度)**：重 / 中 / 轻。

> 🖼️ 图示：时间轴——起始(全 ¹⁵N，重带)→换 ¹⁴N→第1代→第2代，每一步对应离心管的条带位置变化。

---

## Meselson–Stahl：结果与解读（关键！）

- **第 0 代(起始)**：单一**重带 (¹⁵N/¹⁵N)**。
- **第 1 代(复制一次)**：单一**中间带 (¹⁵N/¹⁴N, "hybrid")** —— 介于重与轻之间。
- **第 2 代(复制两次)**：**中间带 + 轻带 (¹⁴N/¹⁴N)**，各约一半。
- 解读：
  - **第 1 代全是中间密度** → 每个分子都是"一重一轻" → **排除 conservative**(它会给"重带+轻带"两条)。
  - **第 2 代出现纯轻带 + 中间带** → **排除 dispersive**(它每代都只给单一、逐渐变轻的带)。
  - 唯一符合 = **semi-conservative**。✅

> 🖼️ 图示：三排离心管(0/1/2 代)条带位置；旁边三假说的"预测条带"对照表，只有 semi 全对勾。

---

## 三种假说的"条带预测"对照

| 假说 | 第 1 代 | 第 2 代 | 与实验是否符合 |
|---|---|---|---|
| **Conservative** | **重带 + 轻带**(两条) | 重 + (多)轻 | ❌(第1代应只见中间带) |
| **Semi-conservative** | **中间带**(单一) | **中间带 + 轻带** | ✅ 完全符合 |
| **Dispersive** | 中间带(单一) | **单一、更轻**的中间带 | ❌(第2代应出现**纯轻带**) |

> 📌 记忆要点：**第 1 代"全中间" → 灭 conservative**；**第 2 代"出现纯轻" → 灭 dispersive**；剩下 **semi-conservative**。

---

## A\* 深化：为什么这个实验如此"漂亮"？

- 它把"看不见的复制方式"转化为**可测量的密度差**——**experimental design** 的典范。
- **¹⁵N→¹⁴N 的切换**像给 DNA"打标记"，使旧链(重)与新链(轻)可被区分。
- 每个假说都给出**互不相同的可证伪预测**(第1、2代条带) → 实验能**唯一地**选出 semi-conservative。
- 🎯 高分意识：被问"该实验如何提供证据"时，要写到——
  1) 第1代**单一中间带**排除 conservative；2) 第2代出现**纯轻带**排除 dispersive；3) 故支持 **semi-conservative**。

> 🖼️ 图示：流程图"假说→预测→实验结果→排除/保留"，突出"可证伪 falsifiable"。

---

## 易错点 & 命令词 — Section 4

- ❌ 说 helicase 断的是"磷酸二酯键/骨架"——它断的是 **hydrogen bonds**。
- ❌ 把 semi-conservative 说成"一半碱基新一半旧"——是**每个分子一整条旧链 + 一整条新链**。
- ❌ 解读 M–S 实验时只说"支持 semi-conservative"却**不说如何排除另外两个**——拿不全分。
- ❌ 把 ¹⁵N/¹⁴N 的"重/轻"对应搞反。

**命令词 Command Words：**
- **Describe** replication = helicase(断氢键)→ template → free nucleotides 互补配对 → DNA polymerase(成 phosphodiester)。
- **Explain how the experiment provides evidence** = 用"假说→预测→排除"三段；**点名** conservative/dispersive 被排除的原因。

# Section 5 🔡
# The Genetic Code
# 遗传密码

本节预告：triplet code / codon；特征——**degenerate、non-overlapping、universal**；start/stop codons；gene → polypeptide 的关系。

---

## 🪝 Hook：只有 4 个字母，如何编码 20 种氨基酸？

- 蛋白质由 **20 种氨基酸** 构成，而 DNA 只有 **4 种碱基 (A,T,C,G)**。
- 若 **1 个碱基**编码 1 个氨基酸：只能编 4 种(不够)。
- 若 **2 个碱基**一组：$4^2 = 16$ 种(还是不够)。
- 若 **3 个碱基**一组：$4^3 = \textbf{64}$ 种 → **足够**编码 20 种氨基酸(还有富余)！
- 🤔 这就是为什么遗传密码是 **triplet（三联体）**——本节解读它的"语法规则"。

> 🖼️ 图示：数学推演 $4^1=4$、$4^2=16$、$4^3=64$ 三档，只有 64 ≥ 20 打勾；旁标 "the code must be in threes"。

---

## 三联体密码 Triplet Code / Codon

- **Triplet code（三联体密码）**：DNA(及 mRNA)上**每 3 个连续碱基**编码**一个氨基酸**。
- 在 **mRNA** 上，这 3 个碱基一组称为 **codon（密码子）**。
- $4^3 = 64$ 个可能的 codon，对应 20 种氨基酸 + 起止信号。
- **Gene（基因）**：DNA 上编码**一条多肽(polypeptide)**(或一个功能产物)的一段碱基序列。
- ⭐ 关系链：**gene(碱基序列) → 决定 codon 序列 → 决定氨基酸序列(primary structure) → 决定蛋白质形状与功能**。

> 🖼️ 图示：一段 mRNA 被竖线切成一个个三碱基"格子"，每格(codon)下面对应一个氨基酸珠子。

---

## 特征①：Degenerate 简并性

- **Degenerate code（简并的密码）**：**多个不同的 codon 可以编码同一个氨基酸**。
- 原因：64 个 codon > 20 个氨基酸 → 大多数氨基酸由 **2–6 个** codon 编码。
- 例：leucine 由 6 个 codon 编码；多数"同义" codon 仅**第 3 个碱基**不同。
- **意义(A\*)**：第 3 位的某些点突变可能**不改变氨基酸 (silent mutation 沉默突变)** → 对蛋白无影响 → **降低突变危害**(衔接 2C)。

> 🖼️ 图示：4 个不同 codon(如 GUU/GUC/GUA/GUG)都用箭头指向同一个氨基酸 "Valine"；标 "degenerate"。

---

## 特征②：Non-overlapping 非重叠

- **Non-overlapping code（非重叠的密码）**：每个碱基**只属于一个** codon，codon 一个接一个、**不共用**碱基。
- 从一个固定起点开始，"每 3 个一读"，互不重叠。
- 对比(反例)：若重叠，一个碱基的改变会影响**多个**氨基酸——而实际并非如此。
- **意义**：阅读框 **reading frame** 清晰；但也意味着**插入/缺失一个碱基会移码 (frameshift)**，改变其后所有 codon(2C 突变会用)。

> 🖼️ 图示：序列 AUG CAU GCU 被"非重叠"地切成 [AUG][CAU][GCU]；旁边画一个"重叠读法"并打叉。

---

## 特征③：Universal 通用性

- **Universal code（通用的密码）**：在**几乎所有生物**中，**同一个 codon 编码同一个氨基酸**(从细菌到人)。
- 例：AUG 在绝大多数生物中都编码 methionine(并作为 start)。
- **意义(A\*)**：
  - 支持所有生物**共同祖先**的进化证据。
  - 是 **genetic engineering / 基因技术** 的基础——人类基因可在细菌中表达(如细菌产**人胰岛素**，衔接 8C)。
- ⚠️ "几乎"：少数例外(如线粒体)存在，但**考试默认 universal**。

> 🖼️ 图示：细菌、植物、人三种生物共用同一张"codon→氨基酸"表；箭头标 "same code → human gene works in bacteria"。

---

## Start 与 Stop Codons

- **Start codon（起始密码子）= AUG**：标记翻译**起点**，同时编码 **methionine**。
- **Stop codons（终止密码子）= UAA, UAG, UGA**：**不编码氨基酸**，标记翻译**终止** → 多肽链释放。
- 三个 stop codon 常记作 **"U Are Annoying / U Are Gone / U Go Away"** 之类助记(任选一种)。
- ⭐ 翻译从 **AUG** 开始，沿 mRNA 一个 codon 接一个读，直到遇到 **stop codon** 停止。

> 🖼️ 图示：一条 mRNA：开头 AUG(绿,start)，中间若干 codon，结尾 UAA(红,stop)；箭头标"翻译方向 5′→3′"。

---

## 三大特征 + start/stop 一览

| 特征 Feature | 含义 | 意义/后果 |
|---|---|---|
| **Triplet** | 3 碱基 = 1 氨基酸 | $4^3=64$ 足以编码 20 种 |
| **Degenerate** | 多 codon → 同氨基酸 | 沉默突变、降低突变危害 |
| **Non-overlapping** | 碱基不共用 | reading frame 清晰；移码风险 |
| **Universal** | 各生物通用 | 进化证据 + 基因工程基础 |
| **Start / Stop** | AUG / UAA,UAG,UGA | 界定翻译起止 |

> 📌 速记四特征：**"三、简、非、通"**(Triplet, Degenerate, Non-overlapping, Universal)。

---

## Key Terms — The Genetic Code

| English term | 中文 | 一句话定义 |
|---|---|---|
| Triplet code | 三联体密码 | 每 3 个碱基编码 1 个氨基酸 |
| Codon | 密码子 | mRNA 上编码一个氨基酸的 3 碱基 |
| Gene | 基因 | 编码一条多肽的 DNA 序列 |
| Degenerate | 简并的 | 多个 codon 编码同一氨基酸 |
| Non-overlapping | 非重叠的 | 碱基不被相邻 codon 共用 |
| Universal | 通用的 | 各生物中 codon 含义相同 |
| Start / Stop codon | 起始/终止密码子 | AUG / UAA, UAG, UGA |

---

## A\* 深化：为什么"简并性"对生物有利？

- 64 codon vs 20 氨基酸 → 大量**同义 codon**(多见于第 3 位)。
- **后果**：
  - **点突变若发生在第 3 位**，常常仍编码同一氨基酸 → **silent mutation** → 蛋白不变 → 表型不受影响。
  - 即使改变，也常变成**化学性质相近**的氨基酸 → 影响较小。
- **所以呢**：简并性是一种**容错/缓冲**机制，降低 DNA 突变对蛋白质的破坏概率(直接衔接 2C 基因突变)。
- 🎯 高分写法：把"degenerate → some base substitutions are silent → no change to amino acid sequence/protein → reduces harmful effect of mutation"写成一条因果链。

> 🖼️ 图示：一段 codon 第 3 位由 U→C，氨基酸不变(仍 Valine)，标 "silent mutation, protein unchanged"。

- ❌ 说"degenerate = 一个 codon 编码多个氨基酸"——是**多个 codon 编码同一个氨基酸**(方向别反)。
- ❌ 把 codon 说成在 DNA 上——**codon 在 mRNA 上**(DNA 上对应的叫 triplet)。
- ❌ 忘了 **stop codon 不编码氨基酸**。
- ❌ 把 universal 理解成"每个生物密码不同"——恰恰相反，是**通用相同**。

# Section 6 🏭
# DNA and Protein Synthesis
# DNA 与蛋白质合成

本节预告：**transcription（转录）**——RNA polymerase、template strand、mRNA、在 nucleus；**translation（翻译）**——ribosome、tRNA anticodon、codon–anticodon、peptide bond、polypeptide；完整 **gene → mRNA → protein** 流程。

---

## 🪝 Hook：基因在核内，蛋白质在核外——信息如何"出核"？

- 真核细胞的 **DNA 被关在 nucleus(细胞核)内**，无法离开。
- 但蛋白质在 **细胞质 (cytoplasm)** 的 **ribosome(核糖体)** 上合成。
- 🤔 信息如何从核内 DNA"传"到核外的核糖体？
- 答案：先把基因**转录 (transcription)** 成一份可移动的"拷贝" **mRNA**，mRNA 出核 → 在核糖体上**翻译 (translation)** 成蛋白质。
- 这就是分子生物学的 **central dogma(中心法则)**：**DNA → RNA → protein**。

> 🖼️ 图示：细胞剖面——核内 DNA 转录成 mRNA，mRNA 穿过核孔到细胞质核糖体，翻译出多肽链；箭头标 "DNA→mRNA→protein"。

---

## 总览：两大阶段 Transcription + Translation

- **阶段一 Transcription（转录）**：在**细胞核内**，以 DNA 的一条链为模板，合成 **mRNA**。
- **阶段二 Translation（翻译）**：在**细胞质的核糖体**上，按 mRNA 的 codon 序列，把氨基酸连成**多肽 (polypeptide)**。
- 衔接：mRNA 经**核孔 (nuclear pore)** 离开细胞核 → 到达核糖体。
- ⭐ 记忆：**Transcription = 抄写(DNA→RNA，同为核酸语言)**；**Translation = 翻译(RNA 碱基语言→氨基酸语言)**。

> 🖼️ 图示：两个大方框——左"Transcription(in nucleus): DNA→mRNA"，右"Translation(at ribosome): mRNA→polypeptide"，中间用 mRNA 出核箭头连接。

---

## Transcription 转录（步骤详解）

1. **DNA helicase / RNA polymerase** 使该基因区段的双链**解开**，打断 **hydrogen bonds**，露出碱基。
2. 其中**一条链作模板 (template / antisense strand)**。
3. 游离的 **RNA nucleotides** 按**互补配对**与模板碱基结合：A→U、T→A、C→G、G→C。
   - ⭐ 注意：RNA 用 **uracil(U)** 配模板上的 **A**(不是 T)。
4. **RNA polymerase（RNA 聚合酶）** 把相邻 RNA 核苷酸用 **phosphodiester bonds** 连成 **mRNA** 链。
5. mRNA 完成后脱离 DNA；DNA 双链**重新闭合**(氢键复原)。

> 🖼️ 图示：DNA 解开一段，模板链上方游离 RNA 核苷酸按互补配对嵌入，RNA polymerase 把它们连成 mRNA(标 U 配 A)。

---

## 模板链与 mRNA 序列对应（关键技巧）

- **Template (antisense) strand 模板链**：被转录的那条；mRNA 与它**互补**。
- **Coding (sense) strand 编码链**：另一条；其序列与 mRNA **相同**(只是 T 换成 U)。
- **例：**
  - Template strand: `3′– T A C  G G A  T T C –5′`
  - mRNA:           `5′– A U G  C C U  A A G –3′`(A配T→…注意 U 配 A)
- ⭐ 实操：先认准**模板链**，再用互补规则写 mRNA(**T→A, A→U, C→G, G→C**)。

> 🖼️ 图示：上下两行——template strand 与其互补 mRNA 对齐，逐碱基用虚线连，红字标 "A on DNA → U on mRNA"。

---

## Translation 翻译（步骤 1）：起始

- 完成的 **mRNA** 经核孔离开细胞核，与 **ribosome（核糖体, 由 rRNA + protein 构成）** 结合。
- 核糖体在 mRNA 上从 **start codon (AUG)** 开始读取，**一次容纳两个 codon**。
- 第一个 **tRNA** 携带与 AUG 互补的 **anticodon (UAC)** 及对应氨基酸(methionine)进入，**codon–anticodon 配对**(靠氢键)。
- ⭐ **tRNA**：一端是 **anticodon**(3 碱基)，另一端携带**特定氨基酸**——它是"碱基语言"与"氨基酸语言"的**翻译官/适配器**。

> 🖼️ 图示：核糖体跨在 mRNA 上(露出 AUG)，一个 tRNA(底端 anticodon UAC，顶端挂 Met)对位嵌入。

---

## Translation 翻译（步骤 2）：延伸与成肽键

1. 第二个 **tRNA**(携对应氨基酸)进入核糖体的第二个位点，其 **anticodon 与第二个 codon 互补配对**。
2. 核糖体催化两个氨基酸间形成 **peptide bond(condensation)** → 多肽链延长。
3. 第一个 tRNA **释放**(卸下氨基酸，离开去再装载)；核糖体**沿 mRNA 移动一个 codon (translocation)**。
4. 新 tRNA 不断进入、配对、成肽键……如此循环，多肽链**逐个氨基酸延长**。

> 🖼️ 图示：核糖体内两个 tRNA 并排，其携带的氨基酸之间形成 peptide bond；箭头表示核糖体向右(沿 mRNA)移动一格、空 tRNA 离开。

---

## Translation 翻译（步骤 3）：终止与折叠

- 核糖体移动到 **stop codon (UAA / UAG / UGA)** 时：
  - **没有对应的 tRNA / anticodon** → **不再加入氨基酸**。
  - 多肽链**释放 (released)**，核糖体与 mRNA 解离。
- 释放的**多肽链折叠**成其 secondary / tertiary(/quaternary) 结构 → 成为**功能蛋白 (protein)**。
- ⭐ 完整信息流：**gene(DNA) →(转录)→ mRNA →(翻译)→ polypeptide →(折叠)→ functional protein**。

> 🖼️ 图示：核糖体抵达红色 stop codon，多肽链脱落并折叠成球状蛋白；下方标完整流程箭头 "DNA→mRNA→polypeptide→protein"。

## Transcription vs Translation 对比

| | **Transcription 转录** | **Translation 翻译** |
|---|---|---|
| 场所 Location | 细胞核 **nucleus** | 核糖体 **ribosome**(细胞质) |
| 模板 Template | DNA 模板链 | mRNA |
| 产物 Product | **mRNA** | **polypeptide / protein** |
| 关键酶/结构 | **RNA polymerase** | **ribosome (rRNA)** + tRNA |
| 配对 Pairing | DNA–RNA(A→U, T→A, C–G) | codon–**anticodon** |
| 连接键 | phosphodiester(核苷酸间) | **peptide bond**(氨基酸间) |

> 📌 一句话：**转录在核内抄出 mRNA(RNA polymerase)**；**翻译在核糖体上把 codon 译成氨基酸链(tRNA + peptide bond)**。

## A\* 深化：codon–anticodon 与互补配对的"统一逻辑"

- 整条信息流其实由**同一条规则**驱动：**complementary base pairing(互补配对)**。
  - 复制：DNA 模板 ↔ 新 DNA 链。
  - 转录：DNA 模板 ↔ mRNA(A→U)。
  - 翻译：mRNA codon ↔ tRNA anticodon。
- **所以呢**：只要记牢"互补配对"，三大过程的"对位"逻辑全部贯通。
- 🎯 写翻译题务必区分：**codon 在 mRNA 上**、**anticodon 在 tRNA 上**，二者**互补**；氨基酸由 **anticodon 所属 tRNA** 携带。
- ⚠️ 真核 mRNA 在出核前还会**加工(剪接 splicing)**(2C/3C 衔接)，本课层级了解即可。

> 🖼️ 图示：三排并列(replication / transcription / translation)，每排都用同一种"互补虚线"连接，标 "all driven by complementary base pairing"。

## 易错点 & 命令词 — Section 6

**常见错误 Misconceptions：**
- ❌ 把 transcription 与 translation 的**场所/产物搞反**(转录在核出 mRNA；翻译在核糖体出多肽)。
- ❌ 说转录用 **DNA polymerase**——转录用 **RNA polymerase**。
- ❌ 把 **codon** 说成在 tRNA 上——codon 在 **mRNA**，**anticodon** 在 **tRNA**。
- ❌ 忘了 RNA 用 **U 配 A**(写成 T)。
- ❌ 说 stop codon"编码一个终止氨基酸"——它**不编码氨基酸**。

**命令词 Command Words：**
- **Describe transcription** = nucleus / template strand / RNA nucleotides 互补(A→U) / **RNA polymerase** / mRNA。
- **Describe translation** = ribosome / mRNA codon / tRNA **anticodon** 互补 / **peptide bond** / 到 stop codon 释放。

## Apply：用"变性"分析生食与酶补充剂

- **主张**："煮熟会破坏酶，所以吃生的能补充酶。"
- **Apply 生物学**：
  - 烹饪的**高温**确实会使食物中的酶**denature(变性)** → 失去活性。✔️(这部分对)
  - 但口服酶补充剂(或生食酶)进入**胃**，**胃酸 pH ~2** 极低 → 多数酶**变性失活**(蛋白被 pepsin 水解)。✘
  - 人体本就能分泌**自身**消化酶(amylase/protease/lipase) → 健康人通常**不需要**外源酶。
- **结论**：除特定**酶缺乏症**(如胰功能不全)患者外，"补酶"对多数人**益处有限**。

## Evaluate：生物洗涤剂——优点与局限

- **优点 Benefits**：
  - 酶在**低温**下高效去污 → **节能、降碳排**；对衣物纤维更温和。
  - **specificity**：protease 去蛋白渍、lipase 去油渍、amylase 去淀粉渍——针对性强。
- **局限 / 风险 Limitations**：
  - 酶有**最适 pH/温度**：水太烫会**变性**失效；需配合合适配方。
  - 部分人可能对酶**过敏 (allergic)**；酶活性受硬水/漂白剂影响。
  - 酶为蛋白质，可能在储存中**逐渐失活**。
- **评价结论**：在**适宜条件**下，生物洗涤剂是有据可循的有效技术，但"越热越好"是误区。

## Core Practical 复盘：实验设计"满分清单"

## Maths Skills ①：从图算速率(梯度)

## Maths Skills ②：初始速率(切线)范例

**情境：** catalase 反应，$O_2$ 体积-时间曲线在起点弯曲。在 $t=0$ 作切线，切线经过 $(0,0)$ 与 $(8,40)$。

## Maths Skills ③：$Q_{10}$ 与百分比变化

**$Q_{10}$：** $Q_{10}=\dfrac{\text{rate at }(T+10)}{\text{rate at }T}$。
- 例：30°C 速率 6.0、20°C 速率 3.0 → $Q_{10}=6.0/3.0=\textbf{2.0}$。

**% change：** $\%\,\text{change}=\dfrac{\text{final}-\text{initial}}{\text{initial}}\times100$。
- 例：加抑制剂后速率由 $4.0$ 降到 $1.0$ → $\dfrac{1.0-4.0}{4.0}\times100=\textbf{-75\%}$。

## Maths Skills ④：Chargaff 碱基比例(综合)

**规则：** 双链 DNA：%A=%T、%C=%G；总和 100%。

**例题 1：** %C = 22% → %G=22%；C+G=44% → A+T=56% → %A=%T=**28%**。

**例题 2(比值)：** 若 $\dfrac{A+T}{C+G}=1.5$，求 %G。
- 设 C+G = x → A+T = 1.5x；总和 $2.5x=100$ → $x=40$ → C+G=40% → %G=**20%**。

## 数据分析示范：酶动力学三步法(综合)

|---|---|---|---|---|---|
| Rate /µmol s⁻¹ | 10 | 19 | 32 | 40 | 41 |

**Q4.** In the Meselson–Stahl experiment, the **first** generation after switching ¹⁵N→¹⁴N showed a single band of **intermediate** density. This rules out:
A. semi-conservative replication
B. conservative replication
C. dispersive replication
D. both conservative and dispersive

**Q5.** During translation, the part of tRNA that pairs with an mRNA codon is the:
A. anticodon  B. codon
C. active site  D. start codon

---

## MCQ 答案 + 干扰项分析

- **Q1 = C.** 酶**降低 $E_a$**。A 酶不升温；B 不改变反应物能量；D 酶**不改变**平衡位置(只加速)。
- **Q2 = B.** **C–G 3 个氢键**；A(A–T)是 2 个；C(A–U)2 个；D 不是合法配对。
- **Q3 = C.** 非竞争性**结合 active site 以外、使其变形**。A/B 描述的是**竞争性**；D 错——抑制剂不"升高 $E_a$"。
- **Q4 = B.** 第1代**单一中间带**只排除 **conservative**(它会给两条带)；dispersive 也给中间带，需到第2代才排除，故不能选 C 或 D。
- **Q5 = A.** tRNA 上与 codon 配对的是 **anticodon**。B codon 在 mRNA；C active site 是酶的；D start codon 在 mRNA。

> 💡 MCQ 技巧：先圈关键词(如 *three* H-bonds / *first* generation / *non-competitive*)，再逐项排除。

## Structured Q1（结构题，含酶图数据，8 分）

**A student investigated the effect of temperature on the rate of an enzyme-catalysed reaction, measuring the volume of gas produced. The graph (described) shows rate rising from 0°C, peaking at 40°C, then falling sharply to near zero by 60°C.**

(a) Describe and explain the shape of the graph **between 0°C and 40°C**. **[3]**

(b) Explain the shape of the graph **above 40°C**. **[3]**

(c) The rate at 20°C was $2.0\ \text{cm}^3\,\text{s}^{-1}$ and at 30°C was $4.2\ \text{cm}^3\,\text{s}^{-1}$. Calculate $Q_{10}$. **[2]**

✍️ 先独立作答（建议 10 分钟），再看下一页 mark scheme。

---

## Structured Q1 — Mark Scheme

**(a) [3]:** 1) as temperature rises the **rate increases**; 2) molecules gain **kinetic energy** → **more frequent successful collisions** between enzyme and substrate; 3) more **enzyme–substrate complexes** form per unit time. (each ✓)

**(b) [3]:** 1) above the optimum (40°C) the rate **falls** (to near zero); 2) **hydrogen/ionic bonds break**, so the enzyme/**active site changes shape (denatures)**; 3) substrate **no longer complementary / cannot bind** → fewer ES complexes. (each ✓)

**(c) [2]:** $Q_{10}=\dfrac{4.2}{2.0}$ ✓ $= \textbf{2.1}$ ✓ (no units; 2 s.f.).

> 💡 得分关键：(a) 写 kinetic energy/collisions/ES complexes；(b) 必含 "active site changes shape → not complementary"；(c) 注意有效数字、无单位。

## Structured Q2（结构题，DNA/复制，7 分）

**(a)** Describe the structure of a DNA molecule. **[4]**

**(b)** A double-stranded DNA molecule contains **18% adenine**. Calculate the percentage of **cytosine**. Show your working. **[2]**

**(c)** Explain why DNA replication is described as **semi-conservative**. **[1]**

✍️ 先独立作答，再看下一页 mark scheme。

---

## Structured Q2 — Mark Scheme

**(a) [4]** (any 4):
- made of **nucleotides** (each = deoxyribose + phosphate + base); 
- **two (antiparallel) strands** / a **sugar–phosphate backbone** joined by **phosphodiester bonds**;
- strands held by **hydrogen bonds** between **complementary bases**;
- **A pairs with T (2 H-bonds)** and **C pairs with G (3 H-bonds)**; coiled into a **double helix**. (each ✓, max 4)

**(b) [2]:** %A = 18% so %T = 18% → A+T = 36% → C+G = 64% ✓ → %C = $64/2 = \textbf{32\%}$ ✓.

**(c) [1]:** each new molecule has **one original (parental) strand and one new strand** ✓.

> 💡 得分关键：(a) 一定写 "A–T 2 / C–G 3 hydrogen bonds + phosphodiester + antiparallel"；(b) C 是 C+G 的一半。

## Structured Q3（结构题，蛋白质合成，6 分）

**Part of an mRNA molecule has the base sequence: `5′– A U G  G C A  U U U  U A A –3′`.**

(a) Using this sequence, state the **DNA template strand** sequence that it was transcribed from. **[2]**

(b) State the **anticodons** of the tRNA molecules that bind to the codons `GCA` and `UUU`. **[2]**

(c) Explain what happens when the ribosome reaches the codon `UAA`. **[2]**

✍️ 先独立作答，再看下一页 mark scheme。

---

## Structured Q3 — Mark Scheme

**(a) [2]:** mRNA `5′–AUG GCA UUU UAA–3′` → template `3′–**TAC CGT AAA ATT**–5′` ✓✓ (complementary: A↔T, U↔A, G↔C, C↔G).

**(b) [2]:** anticodon for `GCA` = `**CGU**` ✓; anticodon for `UUU` = `**AAA**` ✓ (complementary to codon).

**(c) [2]:** 1) `UAA` is a **stop codon** — **no tRNA/anticodon** binds / no amino acid added; 2) the **polypeptide is released** (translation ends). (each ✓)

> 💡 得分关键：DNA 模板用互补(注意 **U→A**)；anticodon 与 codon 互补；stop codon **不加氨基酸 → 释放多肽**。

## A\* 答题技巧总结 / Top Exam Tips

- **酶机制题**写全因果链：condition change → **active site changes shape** → not complementary → fewer ES complexes → rate ↓。
- **升温有利段**必写：**kinetic energy → successful collisions → more ES complexes**。
- **抑制剂题**先判 **$V_{max}$**：不变=competitive(可被底物克服)，降低=non-competitive。
- **DNA 题**：永远写 **A–T 2 / C–G 3 hydrogen bonds**、**phosphodiester**、**antiparallel**。
- **M–S 题**：用"band 位置/数量"**点名排除** conservative 与 dispersive。
- **蛋白合成题**：分清 **codon(mRNA)** 与 **anticodon(tRNA)**；RNA 用 **U**；stop codon 不加氨基酸。
- **计算题**：带单位、看 s.f.、$Q_{10}$ 无单位、% change 看正负号；比较条件用 **initial rate**。

---

## 高频失分点 Top Pitfalls

- ❌ 说酶"提供能量/被消耗/改变平衡"；把 active site 当整个酶。
- ❌ denature 写成"killed"或"可逆"；底物饱和写成"底物用完"。
- ❌ competitive/non-competitive 对 $V_{max}$ 影响搞反。
- ❌ **A–T/C–G 氢键数写反**；RNA 写成含 thymine。
- ❌ phosphodiester 当成连两条链的键(连两链的是 hydrogen bonds)。
- ❌ M–S 只说"支持 semi"不说**如何排除**另两个。
- ❌ 转录写 DNA polymerase；codon/anticodon 张冠李戴；忘了 RNA 用 U。
- ❌ 计算漏单位、$Q_{10}$ 加单位、% change 弄错分母。
